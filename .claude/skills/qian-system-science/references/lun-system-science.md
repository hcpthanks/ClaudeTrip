# 《钱学森论系统科学》

> 上海交通大学钱学森研究中心 编 | 以《智慧的钥匙：钱学森论系统科学》为代表（第二版，2015年）
> 另有《钱学森论系统科学（讲话篇）》（2011）和《钱学森论系统科学（书信篇）》（2012）两卷

---

## 一、地位与定位

《钱学森论系统科学》系列是钱学森系统科学思想的**最完整原典汇编**。与《论系统工程》和《创建系统学》不同，这套书由专业的钱学森研究中心从原始讲话录音、信件手稿中整理而成，**包含了大量首次公开的一手材料**。

三种形态：
- **《智慧的钥匙：钱学森论系统科学》**（2015，第二版）— 精选本，适合入门
- **《钱学森论系统科学（讲话篇）》**（2011，科学出版社）— 首次公开 1986-1994 年系统学讨论班讲话
- **《钱学森论系统科学（书信篇）》**（2012，科学出版社，姜璐编）— 277 封学术通信，1961-1998 年

## 二、全书结构（以《智慧的钥匙》第二版为代表）

### 第一部分：系统科学的体系结构

核心文章：
- 《现代化、技术革命与控制论》
- 《组织管理的技术——系统工程》
- 《系统思想和系统工程》
- 《我对系统学认识的历程》
- 《再谈系统科学的体系》
- 《现代科学的结构——再论科学技术体系学》

**这一部分的核心命题**：系统科学是什么？它在整个科学体系中处于什么位置？它的内部结构是怎样的？

### 第二部分：开放的复杂巨系统与综合集成方法

核心文章：
- 从定性到定量综合集成法（1989-1992 年多篇论述）
- 综合研讨厅体系
- 总体设计部思想
- 大成智慧工程

**这一部分的核心命题**：遇到真正的复杂系统怎么办？有没有超越还原论的方法？

### 第三部分：系统工程的发展与实践

核心文章涵盖：
- 社会工程 — 把系统工程用于国民经济管理
- 军事系统工程 — 国防现代化
- 科研系统工程、环境系统工程、农业系统工程等

**这一部分的核心命题**：系统工程怎么落地？在各个领域怎么用？

## 三、讲话篇与书信篇的独特价值

### 讲话篇（1986-1994 年系统学讨论班）

系统学讨论班是钱学森亲自主持的、持续长达 7 年半的学术活动。讲话篇首次公开了钱学森在讨论班上的即席发言和系统阐述。

这些讲话是**活的思想史**——你能看到钱学森如何从一个观点推导出另一个观点，如何回应质疑和讨论，如何逐步完善自己的体系。

### 书信篇（277 封，1961-1998 年）

书信篇按系统科学的结构编排，展示了钱学森与 77 位/组学者的长期学术对话。

通信对象包括：于景元、戴汝为、汪成为、钱学敏、王寿云等。这些信件是**思想的实验室**——很多后来成为体系核心的概念（"开放的复杂巨系统""综合集成""大成智慧"），在信中都有草稿、讨论和演变过程。

## 四、体系结构的完整表述

### 4.1 十大部门

钱学森将现代科学技术分为**十大部门**，每个部门都有"哲学—基础科学—技术科学—工程技术"四层结构：

1. 自然科学
2. 社会科学
3. 数学科学
4. **系统科学**
5. 思维科学
6. 人体科学
7. 行为科学
8. 地理科学
9. 军事科学
10. 建筑科学

**系统科学**是其中之一，与自然科学、社会科学等并列——这是一个非常大胆的学科划分。

### 4.2 系统科学的内部结构（"三个层次一座桥梁"）

```
马克思主义哲学
      ↕
  系统论（桥梁）
      ↕
  系统学（基础科学）      ← 钱学森认为这一层尚待建立
      ↕
  运筹学、控制论、信息论（技术科学）
      ↕
  各类系统工程（工程技术）
```

### 4.3 思维科学与人体科学

钱学森在系统科学之外，还提出了两个相关的独立部门：

**思维科学** — 三种思维形式：
- 抽象（逻辑）思维 — 已有逻辑学研究
- 形象（直感）思维 — 研究薄弱，但对 AI 至关重要
- 灵感（顿悟）思维 — 最难研究

**人体科学** — 人体作为开放的复杂巨系统：
- 中医理论可以被重新解释为"人体复杂巨系统的经验模型"
- 气功、特异功能等现象需要用系统科学方法研究（而非简单否定或神秘化）

## 五、三本书的关系

```
《论系统工程》（1982）
    ↓ 奠定了基础框架
    ├─ 定义了什么是系统工程
    ├─ 提出了"三个层次一座桥梁"
    └─ 确定了系统科学的学科位置

《创建系统学》（2007）
    ↓ 完成了理论核心
    ├─ 定义了"开放的复杂巨系统"
    ├─ 创立了"综合集成方法"
    └─ 提出了"研讨厅"和"大成智慧"

《钱学森论系统科学》（2011-2015）
    ↓ 提供了完整原典
    ├─ 讲话篇：思想演化过程
    ├─ 书信篇：概念的胚胎发育
    └─ 《智慧的钥匙》：精选本入门
```

**三本书构成一个完整的思想体系**：框架 → 核心理论 → 原典验证。
