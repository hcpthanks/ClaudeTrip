## 风格 A：90 年代日式动画

### 风格锚定词（必须）

```
90s Japanese anime, hand-drawn cel animation, soft warm tones,
cinematic, clean line art, nostalgic aesthetic
```

### 色彩盘

| 色名 | 色值 | 用途 |
|------|------|------|
| 暖黄 | #F5E6D0 | 肤色基底、暖光 |
| 樱花粉 | #F4D5D5 | 浪漫、春日 |
| 天空蓝 | #87AEC9 | 天空、冷调点缀 |
| 琥珀暖 | #C9A96E | 黄昏、温暖光 |
| 米白 | #F5F0E8 | 背景、服装 |

色温：4800-5200K | 饱和度：50-70%

### 情绪 → 画面映射

| 情绪 | 面容/表情 | 光线 | 主色+辅色 |
|------|----------|------|-----------|
| 温馨/日常 | 表情自然，神态松弛 | 均匀暖调，柔和对比 | 暖黄 + 米白 |
| 惊叹/好奇 | 眼睛微睁，表情生动 | 中近景提亮，局部高光 | 暖黄 + 琥珀暖 |
| 思考/内省 | 神情平静，目光悠远 | 柔焦雾化，轻微冷调 | 天空蓝 + 淡紫 |
| 感动/治愈 | 神情温柔，嘴角微扬 | 暖光渐进，轮廓光 | 暖黄 + 琥珀暖 |
| 严肃/专业 | 神情认真，目光清亮 | 明暗层次清晰，中性为主 | 米白 + 高级灰 |
| 兴奋/激情 | 表情灿烂，眼神发光 | 高亮暖调，高饱和 | 暖橙 + 樱花粉 |

### 禁止

无高饱和荧光色、无3D渲染、无现代CG、无过度阴影

## 使用指南

在品质轨生成底图时：

1. 用户选风格 → 查上表 → 注入对应锚定词 + 色彩盘 + 情绪光线映射
2. 底图 prompt 格式：
   ```
   [风格锚定词] + [对应情绪的光线/色调] + [场景描述] +
   "negative space in center, no focal object in middle third,
    dark gradient area for text overlay, visual interest at edges only,
    no text, no watermark, no UI"
   ```
3. Agnes Image 调用尺寸：`size="1792x1024"`（16:9 横屏）

### 风格 → 内容类型适用性

| 风格 | 最适合 | 不适用 |
|------|--------|--------|
| A: 日式动画 | 知识科普、故事讲述、教程 | 技术教程、数据汇报 |
| B: 国风二次元 | 中国文化、历史、哲学 | 科技/AI、西方话题 |
| C: 3D赛博 | AI/科技/未来（非教程） | 传统文化、情感故事 |
| D: 扁平矢量 | 数据汇报、流程讲解、干货 | 情感渲染、品牌大片 |
