# 会话监管哨兵 (Session Supervisor)

> 自动加载规则 — 每次启动和每个项目都生效。
> 与 [command-advisor.md](command-advisor.md) 互补：哨兵检测异常，顾问推荐行动。

## 核心指令

在执行任务过程中，检测到以下任何一种异常信号时，**立即暂停操作**，向用户报告并询问检查问题：

### 6 类异常信号

| # | 信号 | 触发条件 |
|---|------|---------|
| 1 | 🔁 **重复重试** | 同一操作连续失败 ≥2 次 |
| 2 | 📉 **质量回退** | 新方案效果明显不如旧方案 |
| 3 | 🎰 **静默换方案** | 未通知用户就换了技术方案/引擎/参数 |
| 4 | ⏱️ **耗时异常** | 操作耗时超预期 3 倍以上 |
| 5 | 🔄 **隐形循环** | 同类操作 5 分钟内 ≥3 次（即使每次都"成功"） |
| 6 | 🔇 **长时间无反馈** | 连续 ≥60 秒无任何输出给用户 |

### 触发后的标准询问格式

```
⚠️ 哨兵暂停 — 检测到 [异常类型]：[简要描述]

📋 请检查：
1. 流程是否正确？是否偏离了你的目标？
2. 标准是否需要调整？（质量/速度/成本的优先级）
3. 是否需要切换方案？
4. 继续还是停下重新规划？

（你不需要全部回答，选关心的答就行）
```

### 白名单（不触发）

- 用户明确说"多试几次"或"一直试到成功"
- 下载大文件/模型（耗时是预期的）
- 用户说"不用问我"或"你自己决定"
- 正常的单次 bug 修复循环

### 用户控制

- "哨兵关闭" → 暂时禁用
- "哨兵启动" → 重新启用
- "这次不用问" → 单次豁免

### 与关键 Skill 的联动

| Skill | 哨兵行为 |
|-------|---------|
| `ai-video-factory` | 失败 ≥2 次 → 暂停，不自动重试 |
| `autoresearch` | 每轮迭代后检查异常信号 |
| `verification-loop` | 任一阶段失败 → 暂停而非自动修复 |

## 哨兵日志

每次暂停简要记录：`[时间] [异常类型] → 用户决策：[继续/停止/换方案]`
