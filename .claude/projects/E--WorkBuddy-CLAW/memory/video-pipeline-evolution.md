## 视频管线进化史

| 版本 | 管线 | 画面 | 电影感 | 可靠性 | 核心突破 | 教训 |
|------|------|------|:---:|:---:|------|------|
| v1 (6/19前) | ai-video-factory | 纯黑背景 + 白字 | 0 | 100% | TTS 音画对齐 | — |
| v2 (6/19) | Agnes Video 直出 | AI 动态视频 | 2/10 | ~60% | 有了画面 | Agnes 超时/审核失败/不可靠 |
| v2.5 (6/20) | + storyboard-prompter | 11 种风格×情绪映射 | 4/10 | ~60% | prompt 质量×3，解"机器感" | 视觉一致性靠 prompt，不靠工具 |
| v3 (6/22) | Agnes Image → 静态帧 + 淡入淡出 | 风格化静态画面 + xfade | **6/10** | **100%** | 绕过 Video 不可靠，画面稳定不晃 | Zoompan 晃动 = 不如不动 |
| v3.2 (6/24) | Agnes Image + HyperFrames 分层 | AI底图背景 + HTML动效前景 | **7/10** | **95%** | 两层独立互不阻塞，恢复Image引擎地位 | v3.1过度反应：Video不可靠≠Image不可靠 |
| v3.4 (6/29) | 百炼TTS统一 + FFmpeg渐变背景 | 深蓝渐变+标题+字幕 | **5/10** | **100%** | TTS全切百炼、极速轨不依赖Node.js | 文档一致性 = 系统可靠性, 12处矛盾全部清零 |
| v3.5 (6/29) | + OpenMontage借鉴:质量门禁9项+类型承诺+降级规则统一 | 同v3.4, 但加了自动质检和视频类型承诺 | **5/10** | **100%** | 从"机器自动降级"→"检测→告知→等用户确认→执行" | 钱学森"以人为主":机器做检测,人做决策 |
| v3 回退 | ~~Ken Burns zoompan~~ | 静态→慢速位移 | 2/10 | 100% | ❌ 4 秒位移=晃眼，被用户否定 | **不要为了"像视频"加无意义运动** |

## 关键洞察

1. **"画面晃动 ≠ 电影感"** — 切镜方法论说的慢速是让观众沉浸在画面里，不是让画面做机械位移
2. **静态帧 + 淡入淡出 > 拙劣的相机运动** — 配音和字幕才是知识类短视频的主角
3. **Agnes Video 不可靠不是 bug 是特征** — 逼出了 100% 可靠的 Image 管线
4. **每次升级不是换工具，是换思路** — v3 的本质：画面从"主角"退到"氛围背景"
5. **v3.2 教训：降级不要一刀切** — v3.1 因 Video(~60%)不可靠把 Image(~95%)也降级是过度反应。正确做法：分层解耦。
6. **百炼 Wan2.7 是 Agnes Video 的上位替代** — 专业级参数(i2v/r2v/对口型/参考主体)，但付费。Agnes Image(免费)继续做底图。
7. **🆕 v3.5 教训：文档一致性是系统可靠性的基础** — 12处矛盾(TTS引擎/降级规则/版本号/依赖表)被钱学森系统科学审计一次扫出。改一处不改联动=点状修改,累积成债务。
8. **🆕 v3.5 教训：降级必须等人决策** — 机器自动降级偷换方案=对用户撒谎。正确的降级流程: 检测→告知→等用户确认→执行。

## 当前最佳管线（v3.5）

```
文案
  ↓
┌─ TTS: 百炼 DashScope qwen3-tts-flash 中文配音 ─┐
│                                                   │
├─ 极速轨 (默认, teacher_explainer):                │
│   百炼 TTS → FFmpeg 渐变背景+标题+字幕 → 9项质检  │
│   耗时: 1-3分钟 | 依赖: Python+ffmpeg+dashscope   │
│                                                   │
├─ 品质轨 (motion_led, 用户明确要求):               │
│   storyboard-prompter → Agnes Image 底图          │
│   → HyperFrames 文字动效叠加 → FFmpeg 合成        │
│   降级: 检测→告知→等用户确认→执行                  │
│                                                   │
└─ 解说轨 (source_led):                             │
    scenefab: Qwen3.7分镜+DeepSeek解说+百炼TTS      │
└───────────────────────────────────────────────────┘
  ↓
质量门禁 9项 → PASS/FAIL → 完成/降级
```

**How to apply:** 新视频任务默认走极速轨(v3.5)。TTS统一为百炼。降级必须等用户确认,机器不做最终决策。
