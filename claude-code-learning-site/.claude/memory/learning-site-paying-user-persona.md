# 学习站付费用户画像（学习能力画像）

> **定位：** 这是**付费场景**画像——描述学习站付费用户的学习能力、知识范围、购买动机。与 [[default-user-persona]] 互补：通用画像管交互，本画像管内容。

## 目标人群

**一句话：** 40岁以上的个体户小生意人，零基础想学AI但连基础电脑操作都不熟，没人关注但AI真能帮到他们。

## 人群特征

| 维度 | 描述 |
|------|------|
| **年龄** | 40岁以上 |
| **学历/智商** | 小学生级别，不习惯抽象思维 |
| **职业** | 个体户商家，做小生意（夫妻店、摊贩、小店铺） |
| **电脑水平** | 基础电脑知识很薄弱，甚至完全不懂 |
| **系统环境** | Windows（游戏本或办公本） |
| **AI认知** | 零基础，不知道AI是什么，但听说过、想了解 |
| **学习动机** | 想用AI解决自己生意/生活中的实际问题 |
| **付费意愿** | 愿意为"真有用"付费，但金额敏感 |

## 这群人的痛点

| 痛点 | 说明 |
|------|------|
| **被忽视** | 所有AI教程都面向程序员/大学生，没人给他们写 |
| **术语恐惧** | 看到"API""token""prompt"就关页面 |
| **操作恐惧** | 怕把电脑弄坏，怕被骗钱 |
| **不知道该学什么** | AI这个词听过，但从哪开始完全不知道 |
| **学了不知道怎么用** | 即使看了教程，也不知道和自己的小生意有什么关系 |

## 内容设计原则

### 1. 说人话
- 不用任何英文术语（除非必须先解释）
- 用生活类比替代技术概念：token = 字数，prompt = 你打的字，API = 传话筒
- 每解释一个新概念，立刻给一个30秒能看懂的实例

### 2. 有图才看得懂
- 每一步操作必须有截图
- 截图上有红框/箭头标注
- 禁用"如图所示"——图在哪？直接标在图上

### 3. 学了就能用
- 每节课结尾必须有："现在你就能用这个做____"
- 优先教解决生意实际问题的用法（写文案、算账、回消息、做图）
- 不教"Hello World"，教"帮我写一段朋友圈卖货文案"

### 4. 不怕慢
- 假设用户每分钟只能理解一个新概念
- 一个页面只讲一件事
- 步骤不超过3步，超过就拆页

### 5. 给安全感
- 明确告诉用户"这一步不会弄坏你的电脑"
- 每一步操作都是可逆的
- 出错了怎么办——每个操作都给退路

## 定价策略（2026-06-08 更新）

| 方案 | 价格 | 说明 |
|------|------|------|
| **单页解锁** | ¥5 | 解锁一个收费主题的全部内容（④-⑨），仅在课程页付费墙显示 |
| **全站永久** | ¥99 | 应用课+入门课+进阶+专家全部解锁，含未来更新 |

| 原则 | 说明 |
|------|------|
| **先免费后付费** | 预备课7节全部免费；收费课前三步免费试读，满意再买 |
| **不做订阅** | 一次付费永久有效，不搞年付/月付 |
| **不搞限时折扣** | 这批用户觉得"原价999现价99"=骗子 |
| **支付方式单一** | 个人微信收款码 → 发邮件 → 得激活码 |
| **激活码保存在邮箱** | 换电脑换浏览器都不怕，邮件里永远找得到 |

## 典型用户故事

> 老王，45岁，在县城开五金店。手机上只有微信和抖音，电脑是儿子帮买的。听说AI能帮写文案，想知道怎么用，但打开任何AI教程第一页就看不懂了。想花钱学，但不想被骗。需要有人手把手教，从"怎么打开浏览器"开始。

**Why:** 用户明确指出学习站的付费目标用户不是程序员，而是这群"被AI教育忽略的中年小生意人"。教学内容、难度、定价、卖点都需要围绕这个画像重新设计。

**How to apply:** 每次写课程内容、设计付费页、写营销文案时，先用此画像检查：老王能看懂吗？老王觉得有用吗？老王觉得值吗？老王会掏钱吗？
