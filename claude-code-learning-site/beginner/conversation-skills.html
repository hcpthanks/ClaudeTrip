① 为什么它有时听不懂你的话

一句话

AI不是读心术——你给的细节越多，它做出来的东西越对。模糊的话 = 模糊的结果。

🍜 好比你去餐馆点菜

你跟服务员说"来点吃的"——他蒙了。

但你说"一碗牛肉面，微辣，多放葱，少面多汤"——他知道怎么下单。

跟 AI 说话一模一样：你说得越具体，它做得越对。

关键认知：AI很聪明，但它不知道你的情况——你是谁、做什么生意、想要什么风格。这些你得告诉它。多给它一句话，它就少犯一个错。

② 万能公式：我是谁 + 我要什么 + 要什么样的

① 我是谁 → ② 我要什么 → ③ 要什么样的

记住这个公式，每次跟AI说话前花10秒过一遍。熟练了之后根本不用想。

③ 用你的生意套这个公式

不管你做什么生意，这个公式都能用。照着填就行。

✏️ 填空模板

我是____（你的生意），
帮我____（做什么事）。
要求：____（什么样的结果）。

每个做生意的都能用：

🏪 开店的

写促销文案、回客户消息、算利润、做价目表、写活动通知

👔 做批发的

写报价单、整理客户信息、写合作邀约、比价分析

🍜 做餐饮的

写菜单介绍、回复差评、算食材成本、策划节日活动

📦 做电商的

写商品描述、回买家消息、整理订单、写好评回复

④ 好习惯 vs 烂习惯

❌ 烂习惯：想到什么说什么

"帮我写个东西"
"这个改一下"
"再写一个"

每次都让AI猜，猜不对你再改、改完再猜——来来回回浪费时间。

✅ 好习惯：每次套公式

"我是卖茶叶的，帮我写朋友圈文案介绍龙井，口语化80字"

每句话说清楚——AI一遍就做对。

❌ 烂习惯：换话题不重新说背景

刚才让AI写龙井文案，接着又说"帮我写个普洱的"。AI可能不记得你还是卖茶叶的。

✅ 好习惯：每次对话开头先说自己是谁

"我还是那个卖茶叶的。这次帮我写普洱的介绍。要突出年份和口感。"

❌ 烂习惯：AI写错了就骂，不告诉它错在哪

"不对！重写！""还是不对！"

✅ 好习惯：说清楚哪里不对

"太长了，缩到50字"
"太正式了，口语一点"
"把价格加上去"

⑤ 说错了怎么纠正

AI写出来的东西不对——太正常了。别急，也别从头来。告诉它哪里不对就行。

🔄 四步纠错法

1. 看看AI写的东西，找出哪里不满意

2. 用最简单的话说："___一点"

比如："短一点""口语化一点""加上价格""再写两个版本""不要太广告"

3. 看AI改的结果。还不对？再说一次

4. 改了三次还不满意？可能是你一开始没说清。用三步法重新说一遍

别怕改：AI不会嫌你烦。改十次、二十次，它都照做。你越改它越了解你——就像小工跟着你干久了，不用多说就知道你要什么。

⑥ 动手试试

打开 Claude Code，用公式试这几个。每个都先自己填好三个空再说给AI听。

📝 试1

💬 试2

📊 试3

用公式算个账

我是____。帮我算账。收入：____，支出：____。

🔄 试4

试一下纠错——故意不说清楚，AI写出来之后再用"短一点""口语一点"让它改

⑦ 快速掌握清单

问题怎么解决
AI写的东西不对用简单词告诉它哪里不对："短一点""口语一点""加上价格"
改了几次还是不对说明一开始没説清楚。用三步法重新説一遍。
AI忘记之前说了什么每次对话开头重新说一遍"我是谁"。它不一定记得上次的对话。
不知道该让AI做什么想想今天生意上什么事最花时间——写文案、回消息、算账，选一个。
觉得跟AI说话很别扭就当它是你店里新来的小工。你怎么交代小工的，就怎么跟它说。
