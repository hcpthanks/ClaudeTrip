① 它能帮你做什么

一句话说清楚

Claude Code 就是装在你电脑里的一个免费帮手——你打字告诉它要做什么，它帮你做。

🏪 好比你在店里请了个小工

你开了一家店。以前所有事都自己干——写宣传单、回客户消息、算账、整理清单。

现在你请了个小工。你跟他说："帮我写一段朋友圈卖货文案"——他就写了。
你跟他说："帮我算这个月赚了多少"——他就算出来了。
你跟他说："帮我回这条客户消息"——他帮你拟好回复。

这个小工不要工资、不吃饭、一天24小时都在。他就是 Claude Code。

别怕：它不是真人，不会偷你东西、不会骗你钱。它只是你电脑里的一个程序——跟你手机里的计算器一样，只不过它更聪明。

② 看看具体例子

📱 例子1：写朋友圈卖货文案

你对 Claude Code 说：

"我是开五金店的，帮我写一段朋友圈文案，介绍刚到的新款螺丝刀套装。要口语化、80字左右、让人看了想买。"

它就会给你写出一段能直接发朋友圈的文案。

💬 例子2：回客户消息

客户说快递三天没到很生气要退款——你不知道怎么回。你对 Claude Code 说：

"我是开网店的，有个客户说快递三天没到要退款。帮我写一个回复，先道歉，再解释快递慢是天气原因，最后给他补偿5块钱优惠券。"

🧮 例子3：帮你算账

月底了想知道赚了多少。你对 Claude Code 说：

"我是开五金店的。帮我算这个月赚了多少：进货8600，卖货14200，房租2500，水电380。"
💡 注意看这三个例子的共同点：都说了"我是谁"+"我要什么"+"要什么样的"。就像你交代小工干活一样——说清楚了，做出来的东西才合用。

③ 怎么打开它

就两步（别怕，跟着做就行）

第1步：打开 PowerShell

右键点屏幕左下角的开始按钮 → 点"Windows PowerShell"
或者直接按键盘上的 Win键 然后打字 powershell 回车

第2步：输入 claude 然后按回车

出来一个黑窗口不要怕——直接打字 claude 然后回车就行了

⚠️ 第一次用之前：如果你还没装过 Claude Code，需要先装一下。预备课里"安装 Claude Code"这一节手把手教过，忘记的话回去看一眼——跟着做就行，5分钟装好。

④ 跟网页上的 AI 有什么不一样

你可能用过手机上的 AI——比如豆包、Kimi、文心一言。Claude Code 跟它们有什么不同？

手机上的 AIClaude Code
在哪用手机浏览器或 App你电脑里
能看你的文件吗不能能——你让它看哪个文件就看哪个
能帮你整理东西吗不能能——比如整理文件夹、重命名图片
能记住上次对话吗有些能，有些不能能——可以接着上次继续说
要钱吗有些要、有些不要基础功能免费

🏪 打个比方

手机上的 AI 就像打电话问一个远程专家——他看不到你店里什么情况。

Claude Code 就像你店里的小工——他就在你店里，能看到你的货架、你的账本，帮你干活。

最大的好处：Claude Code 在你电脑里，能读你电脑上的文件。你让它"帮我把桌面上的报价单改成表格"，它就能做到。手机上的 AI 做不到。

⑤ 怎么跟它说话

跟 Claude Code 说话，不需要学什么特殊格式。就像你发微信一样——打你想说的话，回车发送。

记住三点就够了

🗣️ 说人话

不用学什么"提示词""指令"。你会怎么交代小工干活，就怎么跟它说。

📋 说清楚

你是谁 + 要做什么 + 要什么样的。说清楚了，出来的结果才对。

🔄 不满意就改

它写出来的东西你不满意？直接说"短一点""口语化一点""加上价格"。它会照着改。

❌ 太模糊

"帮我写个文案"

它不知道你是谁、卖什么、写给谁看——写出来的东西可能完全不对。

✅ 说清楚

"我是开五金店的，帮我写一段朋友圈文案，介绍刚到的新款螺丝刀套装。要口语化、80字左右、让人看了想买。"

⑥ 第一次用它——跟我做一遍

现在就试试。跟着下面的步骤，不超过3分钟。

📋 一步步来

1. 打开 PowerShell（右键开始按钮→Windows PowerShell）

2. 输入 claude 然后回车

3. 等它出现 "有什么我可以帮你的？"

4. 复制下面这句，粘贴进去，回车：

帮我写一段朋友圈文案。我是卖茶叶的，新到了一批龙井，想发朋友圈告诉老客户。要求：口语化、50字左右、让人看了想来买。

5. 看看它写出来什么。满意的话复制到微信发出去。

6. 不满意？接着说："短一点"、"加上价格"、"再写一版"。它会改。

💡 第一次用不用怕：它不会弄坏你的电脑。它就是打字跟你聊天而已——跟你聊微信一样。你说错了重新说就行，它不生气。

⑦ 动手试试

打开 Claude Code，试试下面这几件事。每件都是你做生意用得到的。

📱 试1：写文案

"帮我写一段朋友圈文案。我是卖水果的，今天到的芒果特别甜。要口语化、60字、让人流口水。"

💬 试2：回消息

"帮我回一条客户消息。客户说上次买的货有两个坏的。我先道歉，然后说下次送他两个。口语化。"

🧮 试3：算账

"帮我算账。这个月进货4800，卖货9100，房租2000，水电450，两个员工工资各3000。赚了还是亏了？"

📋 试4：做清单

"帮我列一个明天要做的事情清单。我是开小超市的，明天进货、理货、跟一个供应商谈价格、给老客户发优惠信息。"

你要做什么怎么跟它说（模板）

算账"帮我算账。这个月：进货___，卖货___，开支___。赚了多少？"
写通知/公告"帮我写一个通知。内容是___。要正式一点/口语化一点。"
改文字"帮我把这段话改得___一点：[粘贴你的文字]"
整理信息"帮我把下面这些整理成表格：[粘贴你的内容]"

⑨ 总结：最常用 & 最易错

🎯 记住这三点

✅ 它就是你店里的小工——你怎么交代小工干活，就怎么跟它说。

✅ 说清楚最重要——你是谁 + 要做什么 + 要什么样的。说清楚了，它就做对。

✅ 不满意就让它改——它不是一次性的，说"短一点""换个语气"就行。

⚠️ 别犯这三个错

❌ 说的太模糊——"帮我写个东西"这种话说出来，它只能瞎猜。

❌ 怕它弄坏电脑——它就是聊天，不会删你文件、不会搞坏电脑。

❌ 用一次就放弃——前几次可能不习惯，多用几次就顺手了。跟学骑自行车一样。

🔑 最重要的：现在就去打开 Claude Code，跟它说第一句话。不管是什么——"帮我写一段文案"、"帮我算个账"、"今天天气怎么样"。走出第一步，你就已经超过99%还在观望的人了。
