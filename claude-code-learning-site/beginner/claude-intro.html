① 核心理解：Claude Code 是什么

一句话

Claude Code 是一个运行在你电脑终端里的 AI 编程助手——它不只是聊天，它可以直接读你的代码、写文件、运行命令。

和网页版 Claude 的区别

网页版 ClaudeClaude Code（CLI）
代码感知只能看到你粘贴的代码自动读取整个项目结构
文件操作只能建议修改直接创建、编辑、删除文件
运行命令不能执行可以运行 shell、git、npm 等
上下文单次对话跨会话记忆、项目级配置
多代理不支持可同时启动多个子代理并行工作
安装打开浏览器即可需要在终端里安装

核心概念

Claude Code = AI 模型 + Harness（运行环境）

模型提供智能，Harness 提供能力：读文件、写代码、执行命令、调用工具。
你通过命令行跟它对话，它在你的项目里干活。

② 输入模式：四种跟 Claude Code 对话的方式

模式怎么用什么时候用
交互模式 终端输入 claude，进入对话 日常工作、编码、调试
单次命令 claude -p "你的问题" 快速查询、脚本化调用
管道模式 cat file.txt | claude -p "分析这个" 处理文件内容、日志分析
后台运行 在交互模式中说"在后台运行" 长时间任务、CI/CD 自动化
# 交互模式 — 最常用 claude # 单次命令 — 快速问答 claude -p "这段代码有什么问题？" # 管道模式 — 分析文件 cat error.log | claude -p "找到所有报错并归类"

④ 好用法 vs 烂用法

❌ 烂用法✅ 好用法
提问 "帮我写个网站" "帮我写一个登录页面，用 React + TypeScript，支持邮箱密码登录，错误时显示红色提示"
上下文 不提供相关文件 先让 Claude 读相关文件，再提问
信任 直接 commit Claude 写的代码 每次修改后用 /code-review 审查
规划 上来就让写代码 先用 /plan 做计划，确认后再动手
迭代 一个问题问到底，越跑越偏 每个任务独立开新会话，保持上下文干净
最常见的错误：把 Claude Code 当成搜索工具用。它不是搜索引擎——它是在你的项目里干活的助手。给它足够的上下文，它才做得好。

⑦ 30分钟快速掌握清单

  1. 安装 Claude Code（npm install -g @anthropic-ai/claude-code）
  2. 在任意项目里输入 claude 启动
  3. 说"介绍一下这个项目"——看它怎么理解代码
  4. 让它写一个小功能，用 /code-review 检查
  5. 用 claude -p 试一次单次命令
  6. 给它一个文件路径，让它解释逻辑

⑨ 总结：最常用 & 最易错

🎯 最常用场景

  • 理解陌生代码 — 打开项目，说"介绍下这个项目"
  • 写新功能 — 先用 /plan 做计划，确认后动手
  • 修 Bug — 把报错信息贴给它，让它定位原因
  • 写测试 — 指定文件，让它补单元测试到 80% 覆盖
  • 重构 — 大文件拆小、去重复逻辑、统一命名
  • 日常命令 — claude -p "这个问题" 快速搞定

⚠️ 最常犯错误

  • 当搜索引擎用 — Claude 是项目里的助手，不是 Google
  • 不给上下文 — 不让它先读文件就直接问，答案大概率不准
  • 不审查就 commit — AI 写的代码必须 /code-review 后再提交
  • 会话开太长 — 上下文膨胀后会变笨，新任务用 /clear 开新会话
  • 描述太模糊 — "帮我写个功能" vs "在 settings 页加导出 CSV 按钮"
  • 不信任它能做到 — 先试，不行的再调整，别一开始就觉得它不行
