🎯 第一次让AI帮你做完一件事

从前你可能只是问了AI几个问题。今天不一样——今天你跟AI从头到尾合作，完成一整件事。

① 这次跟以前不一样

之前你可能是这样用的

打开AI → 随便问一句 → 看一眼结果 → 关了。
下次打开 → 又问一句 → 又关了。

这就像你请了小工，但每次只让他干一件小事——他明明能帮你干更多。

今天你要学会的是

打开AI → 说清楚要做什么 → AI做出来 → 不满意就改 → 改到满意 → 保存下来用。

从头到尾做完一件事，不再只是"问一句就走了"。

别怕：这跟前面几课教的东西完全一样。你只是在把"三步法"和"不满意就改"串起来用一次而已。

② 选一件你想做的事

从下面挑一个，或者想你自己的。选好了就记住它——这节课从头到尾都用同一件事。

📱 写一篇朋友圈文案

介绍你的产品/服务，让人看了想买

📋 做一个价目表

把你的产品列成整齐的表格

📢 写一个活动通知

搞个促销，让老客户知道

💬 写几条客户回复模板

以后客户问同样的话就直接用

📊 算这个月的账

🗂️ 整理一个东西

客户名单、库存清单、待办事项——什么都能整理

③ 跟做：从头到尾完成一件事

下面用"写朋友圈文案"做例子。你跟着做就行——换成你选的那件事，步骤一模一样。

⏱️ 第1分钟：打开

打开 PowerShell → 输入 claude → 回车

⏱️ 第2分钟：说清楚

套用三步法，把你要做的事说清楚：

我是卖茶叶的。帮我写一段朋友圈文案介绍新到的龙井。要求：口语化、80字左右、让人看了想买。

⏱️ 第3分钟：看结果

AI写出了文案。读一遍。问自己：能用吗？

如果满意 → 跳到最后一步"保存下来"
如果不满意 → 继续下一步

⏱️ 第4-5分钟：改到满意

用最简单的话告诉AI改哪里：

"太长了，缩到60字"
"太正式了，口语化一点"
"把价格加上"
"换个开头"
"再写两版让我选"

⏱️ 最后一步：保存下来

满意了之后：复制出来，存到你能找到的地方。

复制到微信发出去、存到Word、粘到记事本——随你。关键是下次还能找到。

💡 全程不超过10分钟。第一次可能慢点，做两次就熟了。你刚才做的不只是"问了一个问题"——你是跟AI合作，完成了一整件事。

④ 不满意就改——这是AI最好用的地方

AI跟人最大的区别：人会烦、会累、会偷懒。AI不会。你让改一百次它改一百次。

🔄 改的万能句式

每次只说一个要改的地方：

"____一点"
短一点 · 长一点 · 口语化一点 · 正式一点 · 热情一点 · 客气一点

"加上____"
加上价格 · 加上地址 · 加上电话 · 加上优惠信息

"换成____"
换成列表形式 · 换成表格 · 换成更年轻的语气
最省事的改法：不要一次让AI改三四个地方。一次只改一个，改完看结果，再改下一个。就像捏泥人——捏一下看一下，比一次全捏了再看好。

⑤ AI不是一次性的

很多人以为AI是"打一枪换一个地方"——问一句、关了、下次重新来。其实你可以跟它一直聊下去。

同一件事，可以接着聊

今天让AI写了龙井文案 → 明天打开，跟它说"我还是那个卖茶叶的，今天帮我写普洱的"→ 后天说"帮我写个红茶的活动通知"

AI不嫌烦，越聊越熟。

同一件事，越做越好

第一次写龙井文案花了10分钟改了三回。
第二次写普洱文案花了3分钟只改了一回。
第三次写红茶文案30秒就好了——因为你已经知道怎么跟它说了。

💡 关键习惯：每天打开Claude Code做的第一件事，就是告诉自己"今天我要让AI帮我完成一件什么事"。不要只是"随便问问"——想好一件事，做完它。
