📝 编辑操作

提交消息 Enter 发消息，Shift+Enter 换行
中断生成 Esc 或 Ctrl+C
粘贴（通用终端） Shift+Insert 或右键
粘贴（Windows Terminal） Ctrl+Shift+V

🧭 导航

切换文件 Ctrl+Tab 下一个，Ctrl+Shift+Tab 上一个
跳转到行 Ctrl+G
搜索文件 Ctrl+P

🧠 思考模式

切换扩展思考 Alt+T（Windows）/ Option+T（Mac）
查看思考过程 Ctrl+O（详细模式）
扩展思考让 Claude 花更多时间推理复杂问题——默认开启，一般不用关。

💬 会话管理

清空上下文 输入 /clear
退出 Ctrl+C 或 /exit
帮助 /help

⚡ 最常用的 Slash 命令

/plan 功能实现前做计划
/code-review 审查刚写的代码
/clear 清空对话上下文
/save-session 保存当前会话，下次继续
/resume-session 恢复上次保存的会话
/build-fix 自动修复构建错误
/pr 创建 Pull Request

⑨ 总结：最常用 & 最易错

🎯 每天必用 TOP 6

  • Enter — 发送消息，最频繁的操作
  • Esc / Ctrl+C — 中断 AI 跑偏的输出
  • Shift+Insert / 右键 — 粘贴到终端（Ctrl+V 无效！）
  • /plan — 做任何复杂功能前先规划
  • /code-review — 写完代码立即审查
  • /clear — 话题跑远了就清空重来

⚠️ 最常犯错误

  • 狂按 Ctrl+V 没反应 — 命令行粘贴用 Shift+Insert 或右键，Ctrl+V 是编辑器的习惯
  • 不知道 Esc 可以中断 — AI 跑偏了不要等它说完，直接 Esc 打断
  • 不知道 Alt+T 开关思考 — 复杂任务开启扩展思考，简单任务关闭省时间
  • 没有保存会话习惯 — 长任务中途用 /save-session，防止丢了上下文
  • Slash 命令不用 Tab 补全 — 输 /pla 按 Tab 自动补全 /plan，效率翻倍
