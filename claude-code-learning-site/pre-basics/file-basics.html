① "路径"是什么？

路径 = 电脑里的快递地址
它告诉电脑（和 Claude Code）一个文件到底放在哪里

📦 快递地址 vs 文件路径

快递地址文件路径
中国 / 广东省 / 深圳市 / 南山区 / XX路 / 3号楼 / 502室 C: / Users / 你的名字 / Desktop / 工作文档 / 报告.docx

一样的道理——从大到小，一层一层定位。每一层用 \（反斜杠）隔开。
C: 是你的硬盘，Users 是"用户"文件夹，"你的名字"是你电脑的账户名……

为什么你要学这个？Claude Code 需要知道"你在哪个文件夹里干活"。如果你在桌面文件夹里，它就读桌面的文件；如果你在文档文件夹里，它就读文档的文件。学会切换文件夹 = 学会告诉 AI 去哪里找东西。

② 一步一步来：学会三个命令

今天只学三个命令，但它们是所有操作的基础。

命令作用怎么记
pwd告诉我"我现在在哪个文件夹"Print Working Directory
ls显示这个文件夹里有什么List（列出）
cd 文件夹名进入那个文件夹Change Directory（换文件夹）
  1. 1

    先看看你在哪里：输入 pwd

    打开 PowerShell，输入 pwd，按回车

    你看到的路径是什么？通常是 C:\Users\你的名字——这是你的"用户文件夹"，PowerShell 默认从这里开始。

  2. 2

    看看这个文件夹里有什么：输入 ls

    输入 ls，按回车

    你看到 Desktop（桌面）、Documents（文档）、Downloads（下载）这些名字了吗？它们都是文件夹。

  3. 3

    进入桌面文件夹：cd Desktop

    输入 cd Desktop，按回车。然后再输入 pwd 确认你进来了。

    路径变了吗？现在应该是 C:\Users\你的名字\Desktop。

  4. 4

    看看桌面上有什么：再输入 ls

    现在你在桌面文件夹里了，输入 ls 看看桌面上有什么文件
  5. 5

    回到上一级文件夹：cd ..

    cd 后面跟两个点 .. 表示"回到上一层"
    cd ..

    两个点 .. = 上一层。cd .. = 回到上一级文件夹。

    输入 pwd 确认你回来了——应该又回到 C:\Users\你的名字 了。

🗺️

你学会了电脑里的"找路"！

pwd（看位置）+ ls（看内容）+ cd（换位置）——就这三个命令，够你用了。

③ 再看一遍：三个命令演示

pwd → ls → cd → ls 完整演示（20秒）
三个命令完整演示流程
📍 pwd→ 📋 ls→ 🚶 cd Desktop→ 📍 pwd→ 📋 ls→ ⬆️ cd ..

💡 在 PowerShell 里照着敲一遍——pwd、ls、cd 是你最常用的三个命令

④ 最容易遇到的 3 个问题

坑 1：cd 一个文件夹说"找不到路径"

最常见的原因：文件夹名字拼错了，或者中间有空格。

先用 ls 看看当前文件夹里到底有什么——文件夹名必须完全一样（包括大小写）。如果名字里有空格（比如 "My Documents"），用引号包起来：cd "My Documents"。
坑 2：不知道自己在哪里了

跳来跳去，不知道现在在哪个文件夹。

输入 pwd——任何时候都能用它看位置。这是你最常用的命令之一。
坑 3：路径太长看不懂

像 C:\Users\名字\Documents\Projects\2024\notes.txt 这种。

从右往左读：最后的 notes.txt 是文件名，2024 是它所在的文件夹，Projects 是 2024 的上一层……一层一层往上推。

⑤ 做一遍：动手练习

你的练习任务

1. 打开 PowerShell，输入 pwd——看看你在哪
2. 输入 ls——看看这里有什么
3. cd Desktop——进入桌面
4. ls——看看桌面上有什么
5. cd ..——回到上一级
6. cd Documents——进入文档文件夹（如果有的话）
7. 在每个文件夹里都用 ls 看一眼

💡 练到你能不假思索地用 cd 切换到桌面、切换回用户文件夹。这是 Claude Code 的必备技能。
