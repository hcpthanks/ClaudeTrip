① 这个能帮你做什么

学完这节课，你能叫出电脑屏幕上每样东西的名字。
以后别人跟你说"点开始菜单"、"打开文件夹"，你不会再愣住。

🔧 把电脑想象成你的五金店

电脑上的东西相当于…说明
桌面你的柜台台面放最常用的东西，一开机就能看到
开始菜单柜台下面的抽屉柜所有东西都在里面，点一下就能翻
文件夹抽屉/货架把相关的东西分类收纳，不乱
文件单据/发票记录信息的东西——进货单、客户名单、库存表都是"文件"
窗口你正在翻的那一个抽屉每打开一个程序，就会有一个"窗口"弹出来
别担心：这些东西你每天都在用——只是不知道它们叫什么名字。学完这课你就全知道了。

④ 最容易搞混的 3 件事

坑 1：分不清"单击"和"双击"

单击（点一下）= 选中，东西变蓝。双击（快速点两下）= 打开，弹出新窗口。就像敲一次门是"有人吗"，快速敲两次才是"开门"。

如果点了没反应——试试点快一点。两下之间的间隔要很短（不到半秒）。双击打不开就像连续敲两次门敲太慢——门还没开。
坑 2：以为关了窗口就是删了东西

点 ✕ 只是把这个窗口关掉，就像合上一本书。书还在，下次打开还能看。

想再打开？找到那个文件夹图标，再双击一次就行。
坑 3：找不到刚才打开的东西去哪了

打开的窗口可能被其他窗口挡住了，或者缩到了任务栏上。

看屏幕最下面——任务栏上是不是有个亮着的小标记？点它一下，窗口就回来了。

⑤ 做一遍：动手练习

你的练习任务

1. 指一指：你的桌面在哪里？任务栏在哪个位置？开始菜单（⊞ 图标）在哪？
2. 在桌面上找一个文件夹，双击打开它
3. 看看里面有什么文件——是不是跟你在店里翻抽屉的感觉一样？
4. 点右上角 ✕ 关闭按钮把它关掉
5. 再双击一次打开它（这次你知道了——它没有被删掉，就像合上抽屉，里面的单据还在）

💡 做完了吗？如果 5 步都做到了，你已经比 90% 的电脑新手厉害了。
