🆘 遇到错误怎么办

看到红色报错别慌——这是所有学电脑的人都会遇到的事。这里有解决方法。

① 先说最重要的：报错不是你笨

每一个程序员每天都会遇到报错。
你遇到红色英文就慌，他们遇到红色英文就开始读。
唯一的区别：他们学会了怎么处理。
😱

新手反应

看到红色字→慌了→乱点→问题更糟
→觉得"我不适合学电脑"→放弃

🧠

正确反应

看到红色字→停一下→截图→
看一下它说了什么→按步骤解决

🎯

终极武器

把错误信息复制给 AI
（Claude Code 或网页版 Claude）
AI 能帮你分析并给出解决方案

记住这句话：错误信息不是"你做错了"——它是电脑在告诉你"我不知道怎么继续了，帮帮我"。那些红色的英文是线索，不是批评。

② 遇到错误的"三步法"

不管什么错误，按这三步走——90% 的情况都能解决。

  1. 1

    📸 截图——先别关窗口！

    按键盘上的 Print Screen 键（有的键盘写 PrtScn），或者用手机拍照
    千万别急着关窗口！错误信息和窗口一旦关了，别人想帮你都看不到线索。先截图，再关。
  2. 2

    👀 读——别看是英文就不读

    找到红色字里最关键的一行——通常第一行或者最后一行
    怎么复制 PowerShell 里的文字？用鼠标选中文字（按住左键拖过去），选中的文字会自动复制。然后 Ctrl+V 粘贴到任何地方。或者在选中的文字上点右键。
  3. 3

    🤖 发给 AI——让 AI 帮你分析

    把错误信息复制到 Claude Code 或网页版 Claude，问它怎么回事
    👤 你: 我遇到了这个错误，帮我看看怎么解决：
    npm ERR! code EACCES
    npm ERR! syscall access
    npm ERR! path /usr/local/lib
    npm ERR! errno -13
    🤖 Claude: 这是权限不够的问题。试试在命令前面加上 sudo（Mac）或者用管理员身份运行 PowerShell（Windows）。具体做法是……
🦸

你学会了"自救三步法"

截图 → 读关键行 → 发给 AI。以后遇到任何报错，先深呼吸，然后走这三步。

③ 最常见的 5 个错误（直接抄答案）

以下是你最可能遇到的 5 个错误。如果你的错误跟下面某个一模一样——直接用解决方案。

❌ "claude 不是内部或外部命令"

输入 claude 后出现这个。

Claude Code 没装好。关闭所有 PowerShell 窗口，重新打开。输入 npm install -g @anthropic-ai/claude-code 重新安装。如果还不行，重启电脑。
❌ "npm 不是内部或外部命令"

输入 npm 命令后出现这个。

Node.js 没装或没装好。关闭所有 PowerShell 窗口，重新打开。输入 node --version 验证。如果没有版本号，去 nodejs.org 重新下载安装 Node.js。
❌ "npm ERR! code EACCES" 或 "permission denied"

安装东西时出现的权限错误。

权限不够。右键 PowerShell 图标 → "以管理员身份运行"，然后再执行同样的命令。
❌ "npm ERR! network" 或 "request timed out"

安装下载时网络超时。

网络问题。检查能不能上网（打开浏览器试试百度和谷歌）。如果在国内，可能需要用镜像源：先输入 npm config set registry https://registry.npmmirror.com，再重新安装。
❌ "Cannot find module" 或 "Module not found"

运行 Claude Code 时出现。

安装不完整。尝试重装：npm uninstall -g @anthropic-ai/claude-code 然后 npm install -g @anthropic-ai/claude-code。不行就重启电脑试试。

⑤ 终极秘籍：实在不行怎么办

🔄 重启大法

关掉 PowerShell → 关掉所有跟代码相关的窗口 → 重启电脑 → 重新打开 PowerShell → 再试。

👉 解决率：约 50%。重启能清除很多奇怪的状态。

🔁 重装大法

如果重启还不行——卸载 Claude Code 然后重新安装：

npm uninstall -g @anthropic-ai/claude-code npm install -g @anthropic-ai/claude-code

👉 解决率：约 70%。重新安装能修复大部分安装问题。

🧹 清空重来

如果 Claude Code 能启动但行为奇怪——清空上下文重新开始：

/clear

👉 /clear 会清空当前对话，像"重新打开一个新聊天"。AI 不会记得刚才的话题。

👥 求助大法

以上都试过了还是不行？把截图发到学习群里，或者在 Claude Code 网页版（claude.ai）上传截图问 AI。

描述问题时记住：说清楚"我做了什么 → 期望什么结果 → 实际发生了什么"。
