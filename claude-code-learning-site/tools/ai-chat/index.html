Agnes 2.0 Flash — 1M 上下文窗口 · 65K 输出 · OpenAI 兼容

模型信息

模型名称agnes-2.0-flash
上下文窗口1,000,000 tokens（1M）
最大输出65,536 tokens
格式OpenAI 兼容
费用免费
Base URLhttps://apihub.agnes-ai.com/v1

适用场景

  • 编程辅助 — 写代码、Debug、Code Review
  • 写作润色 — 文章、报告、翻译、摘要
  • Agent 工作流 — 结合 Claude Code 调度多步任务
  • 长文档处理 — 1M 上下文，一次塞进整本书

参数说明

prompt用户消息（必填）
system系统提示词（可选），定义角色和行为
max_tokens最大输出 token 数，最高 65536
temperature创造性控制，0-2，默认 0.7。越低越确定，越高越随机

在 Claude Code 中使用

# 直接对话
直接用中文提问即可，Claude Code 通过 MCP 工具调用 Agnes Chat

# 也可以指定系统提示词
"帮我用 Agnes Chat 翻译这篇文档，system prompt 设为'你是专业翻译'"

# 调整创造性
"用 temperature=0.3 帮我写一段严谨的技术文档"

实战示例

代码生成

帮我用 Python 写一个 Flask API，实现用户注册登录功能：
- 用 SQLite 数据库
- 密码 bcrypt 加密

- 包含完整的错误处理
