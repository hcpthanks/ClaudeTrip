Agnes Image 2.0 Flash — 文生图 · ~5 秒出图 · 高信息密度

模型信息

模型名称agnes-image-2.0-flash
生成速度约 5 秒
支持语言中文 / 英文提示词
特点高信息密度，适合教程配图、封面、示意图
费用免费

支持尺寸

1024x1024正方形，默认尺寸。适合头像、图标、社交媒体帖子
1792x1024横版宽屏。适合视频封面、Banner、博客头图
1024x1792竖版。适合手机壁纸、海报、小红书封面
512x512小尺寸。快速预览、批量生成、头像

参数说明

prompt图片描述（必填），支持中英文
size图片尺寸：1024x1024 / 1792x1024 / 1024x1792 / 512x512
n生成数量，默认 1

在 Claude Code 中使用

# 基础用法
"帮我用 Agnes Image 生成一张图片：一只橘猫坐在电脑前写代码"

# 指定尺寸
"生成一张 1792x1024 的横版图片：未来城市的日出景象，赛博朋克风格"

# 指定风格和细节
"生成一张竖版海报（1024x1792）：标题'AI 帮你干活'，
深色背景，霓虹紫色调，科技感，适合网站首页 Hero"
