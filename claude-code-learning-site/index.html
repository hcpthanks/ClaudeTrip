读懂之后，日子会多出一点什么

不是多背几千个单词。是少了一层翻译。

新书上市那天，我读的是原版。译本还没出。

台词落进耳朵。语气和停顿，都还在。

菜单、告示、邻桌的闲聊。不再是背景音。

读懂了，故事就自己走进来。

把读过的每一页，变成一次练习

看清每个字，听见每句话，问懂每个难点，再回到上次停下的地方。

假名标注字的上方是读音。想自测的时候，把它们收起来。
逐句朗读点右下的大圆钮，从正在读的这一句开始。语速、音色，都可以换。
句子解析选中一句，让它讲讲意思和语法。接本地 Ollama，或者自己的 Key。
栞合上，就是书签按段落记住位置。换字号、改窗口，回来还是那一句。首页写着读到第几章。
