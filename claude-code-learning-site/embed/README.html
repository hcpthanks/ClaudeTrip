🔶 方案B：iframe 嵌入课程内容

把完整课程内容嵌到你的网页里，用户不离开你的网站就能学。

代码（复制即用）

<!-- 把这段代码粘贴到你想显示课程的位置 -->
<iframe
  src="https://www.hcpthanks.com/embed/iframe-content.html"
  width="100%"
  height="400"
  style="border:none;border-radius:12px;max-width:700px;"
  title="AI 帮你干活 — 嵌入式课程"
></iframe>

🟢 方案C：JS Widget（一行代码，自动渲染）

最灵活的方案。一行 <script> 标签，自动在你指定的位置渲染卡片。

最简单用法

<!-- 粘贴到你想显示卡片的位置 -->
<script src="https://www.hcpthanks.com/embed/widget.js"></script>

高级配置

<!-- 指定样式为方块卡片，自定义文字 -->
<script
  src="https://www.hcpthanks.com/embed/widget.js"
  data-style="square"
  data-text="AI帮你干活"
  data-theme="dark"
></script>

<!-- 指定渲染到某个 div 中 -->
<div id="my-card"></div>
<script
  src="https://www.hcpthanks.com/embed/widget.js"
  data-target="#my-card"
  data-style="banner"
></script>
参数可选值默认值说明
data-stylebanner / square / floatbanner卡片样式
data-text任意文字AI 帮你干活卡片标题
data-themedark / lightdark深色/浅色主题
data-targetCSS 选择器（script 所在位置）渲染到哪个容器

❓ 常见问题

能改颜色和文字吗？

可以。方案A：直接改 HTML 里的 style="..." 属性值。方案C：改 data-* 参数。

需要放你们 logo 或者注明来源吗？

不强制。但如果你愿意保留卡片上的链接，我们会非常感谢 🙏

影响我网站的加载速度吗？

不影响。方案A 是纯 HTML（0KB JS），方案C 的 widget.js 只有 ~2KB，加载只需几毫秒。

可以多个卡片放在同一页吗？

可以。方案A 复制多份粘贴到不同位置即可。方案C 用 data-target 指定不同容器。
