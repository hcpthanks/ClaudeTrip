1. 总览：两种视频方案

方案一：iframe 嵌入方案二：本地 mp4
适用场景 长教程、讲解类视频（5分钟以上） 短操作演示（15-60秒）、抖音视频
文件存储 存在 B站/西瓜/腾讯 服务器，不占你空间 mp4 文件放 docs/assets/videos/，占用 Git 仓库空间
加载速度 依赖第三方 CDN，国内快 走 GitHub Pages，首次加载可能略慢
流量成本 零成本，平台承担带宽 零成本（GitHub Pages 无限流量）
播放器样式 平台自带播放器（带水印/跳转链接） 浏览器原生播放器，干净无干扰
CSP 要求 必须在 frame-src 中放行平台域名 无需额外配置
💡 选型建议：长教程 → B站；短操作演示 → 本地 mp4；抖音视频 → 下载后转本地 mp4。

3. 方案一：平台 iframe 嵌入

3.1 获取 B站 BV 号

  1. 用浏览器打开 B站视频页面
  2. 看地址栏：https://www.bilibili.com/video/BV1YUEz6mEMj/?...
  3. BV 开头的那串就是视频 ID，复制它

3.2 完整模板（复制即用）

<!-- ══════ 视频演示 ══════ -->
<div class="video-wrap">
  <div class="video-16x9">
    <iframe src="//player.bilibili.com/player.html?bvid=你的BV号&page=1"
            scrolling="no" frameborder="no" allowfullscreen>
    </iframe>
  </div>
  <p class="video-caption">📺 视频版：安装全过程，跟着做就行</p>
</div>

3.3 关键参数说明

参数说明示例
bvid=BV 视频 ID（必填）bvid=BV1YUEz6mEMj
page=分 P 序号，从 1 开始page=1（第一P）
autoplay=自动播放（建议不设，用户体验差）autoplay=0
danmaku=弹幕开关，0关1开danmaku=0

3.4 西瓜视频模板

<div class="video-wrap">
  <div class="video-16x9">
    <iframe src="//www.xigua.com/embed/?id=视频ID"
            scrolling="no" frameborder="no" allowfullscreen>
    </iframe>
  </div>
  <p class="video-caption">📺 视频版</p>
</div>

3.5 腾讯视频模板

<div class="video-wrap">
  <div class="video-16x9">
    <iframe src="//v.qq.com/txp/iframe/player.html?vid=视频VID"
            scrolling="no" frameborder="no" allowfullscreen>
    </iframe>
  </div>
  <p class="video-caption">📺 视频版</p>
</div>
⚠️ 注意：腾讯视频在部分网络环境下可能加载偏慢，建议优先用 B站。

4. 方案二：本地 mp4 播放

4.1 视频文件放哪里

所有本地视频统一放到：

docs/assets/videos/

如果这个文件夹不存在，创建它：

mkdir docs\assets\videos

4.2 完整模板（复制即用）

<div class="video-wrap">
  <div class="video-label">完整安装流程一览（6 大阶段，14 个步骤，约 30 分钟）</div>
  <video controls muted preload="metadata"
         poster="../assets/videos/封面图.jpg">
    <source src="../assets/videos/你的视频.mp4" type="video/mp4">
    你的浏览器不支持视频播放，请升级浏览器。
  </video>
  <p class="video-caption">🎬 操作演示：打开安装页面（15秒）</p>
</div>

4.3 关键属性说明

属性作用建议
controls显示播放/暂停/进度条控件必须
muted静音（允许自动播放）建议保留
preload="metadata"只预加载元信息（不下载完整视频）必须，省流量
poster视频加载前显示的封面图建议有，否则黑屏
.video-label视频上方标签，前面自动加 🎬 图标建议加，让用户知道要看什么
.video-caption视频下方灰色说明文字可选

4.4 路径规则（重要！）

视频路径是相对于当前 HTML 文件的：

HTML 文件位置src 写法
docs/index.htmlassets/videos/xxx.mp4
docs/pre-basics/xxx.html../assets/videos/xxx.mp4
docs/intermediate/xxx.html../assets/videos/xxx.mp4
⚠️ 子文件夹页面（pre-basics/、applied/、intermediate/）必须加 ../ 前缀！否则视频加载不出来。

4.5 视频文件要求

项目建议值
格式mp4（H.264 编码）—— 所有浏览器都兼容
分辨率720p 或 1080p，不超过 1920×1080
时长15-60 秒（操作演示），长教程请用 iframe 方案
文件大小单个文件建议 <20MB，太大影响 Git 仓库和加载速度
帧率24 或 30fps

5. 专题：抖音视频下载 → 本地播放

抖音不支持 iframe 嵌入，但可以通过下载工具把视频拉下来，转成本地 mp4 播放。

方案 A：用 Claude Code 内置下载器（推荐）

对 Claude 说：

/douyin-downloader https://v.douyin.com/xxxxx/

然后等待下载完成，再把 mp4 文件复制到 docs/assets/videos/。

方案 B：用 yt-dlp 手动下载

# 安装 yt-dlp（一次性）
pip install yt-dlp

# 下载抖音视频
yt-dlp "https://v.douyin.com/xxxxx/" -o "%(title)s.%(ext)s"

# 下载 B站视频（也是这个命令）
yt-dlp "https://www.bilibili.com/video/BV1YUEz6mEMj" -o "%(title)s.%(ext)s"

方案 C：手机录屏

  1. 打开抖音 App，播视频
  2. 用手机自带录屏功能录下来
  3. 通过微信/数据线传到电脑
  4. 放到 docs/assets/videos/
💡 注意：下载的抖音视频可能带有水印。录屏方案无水印但画质略降。

6. 方案三：Smart Placeholder（暂无视频时的占位）

当某个位置计划放视频但还没录好时，用这个占位组件。它用纯 CSS 画一个流程图示意，不会让页面看起来"坏掉了"。

完整模板

<div class="video-wrap">
  <div class="video-label">完整安装流程一览（6 大阶段，14 个步骤，约 30 分钟）</div>
  <div class="smart-placeholder">
    <div class="ph-header"><div class="ph-dot"></div> 国内免魔法使用 Claude Code 完整流程</div>
    <div class="ph-body">
      <div class="ph-preview">
        <div style="display:flex;gap:3px;flex-wrap:wrap;justify-content:center;align-items:center;font-size:0.72em;">
          <span style="background:var(--surface);padding:5px 8px;border-radius:14px;">第一步</span>
          <span style="color:var(--text-muted);">→</span>
          <span style="background:var(--surface);padding:5px 8px;border-radius:14px;">第二步</span>
          <span style="color:var(--text-muted);">→</span>
          <span style="background:var(--surface);padding:5px 8px;border-radius:14px;">第三步</span>
        </div>
      </div>
      <p class="ph-note">💡 视频正在录制中，先看文字教程</p>
    </div>
  </div>
</div>

效果说明

  • .ph-header —— 标题栏，左边有个小绿点
  • .ph-preview —— 流程图展示区，把步骤用 → 箭头串起来
  • .ph-note —— 底部灰色提示文字
💡 替换时机：视频录好后，把整个 .smart-placeholder 块替换成 <video> 标签即可，外层 .video-wrap 和 .video-label 保持不变。

7. CSP 安全策略注意事项

当前 CSP 配置（2026-06-13）

在 docs/index.html 第5行：

frame-src https://player.bilibili.com https://www.xigua.com https://v.qq.com;

如果加了新 iframe 平台，需要做什么

  1. 找到新平台 iframe 的域名（看 embed 代码中 src="//xxx.com/..." 的 xxx.com 部分）
  2. 在 index.html 的 frame-src 后面追加以空格分隔的域名
  3. 必须同时修改两个文件：
    • docs/index.html（线上站点）
    • claude-code-learning-site/index.html（开发副本）
  4. 提交 push 后等待 1-2 分钟（GitHub Pages 延迟）

示例：加 YouTube 支持

frame-src https://player.bilibili.com https://www.xigua.com https://v.qq.com https://www.youtube.com;

9. 完整操作流程

以"给安装 Claude Code 页面加一个 B站教程视频"为例：

  1. 获取 BV 号
    打开 B站视频，复制地址栏中的 BV 号（如 BV1YUEz6mEMj）

  2. 打开 HTML 文件
    用 VS Code / 记事本 打开 docs\pre-basics\install-claude-code.html

  3. 找到视频占位区域
    搜索 方法1：B站嵌入，找到这段注释块

  4. 取消注释 + 替换 BV 号
    把 <!-- 和 --> 删掉，把 XXX 换成真实 BV 号

    <div class="video-wrap">
  <div class="video-16x9">
    <iframe src="//player.bilibili.com/player.html?bvid=BV1YUEz6mEMj&page=1"
            scrolling="no" frameborder="no" allowfullscreen>
    </iframe>
  </div>
  <p class="video-caption">📺 视频版：安装全过程，跟着做就行</p>
</div>

  5. （可选）改标题
    修改 .video-caption 里的文字，改成你的视频标题

  6. 保存，提交，推送

    git add docs/pre-basics/install-claude-code.html
git commit -m "feat: 安装ClaudeCode页面添加B站教程视频 BV1YUEz6mEMj"
git -c credential.helper= -c http.proxy=socks5://127.0.0.1:10808 push origin main

  7. 等 1-2 分钟
    GitHub Pages 部署有延迟，刷新网站就能看到视频

10. 常见问题排查

❌ 视频区域一片空白

原因解决
CSP 拦截了 iframe 域名检查 index.html 的 frame-src 是否包含该平台域名（见第7节）
BV 号写错了B站打开原视频确认 BV 号
B站视频被删除/下架打开 B站原链接确认视频还存在
网络问题（公司/学校屏蔽 B站）用手机流量测试

❌ 视频显示"不支持"或黑屏

原因解决
mp4 编码不是 H.264用 HandBrake 或 ffmpeg 重新编码为 H.264
mp4 文件路径写错了确认 ../assets/videos/ 前缀数量（子文件夹才需要 ../）
mp4 文件没 push 到 GitHub检查 git status，确认文件已 git add

❌ B站视频有水印/跳转链接

原因解决
B站播放器自带，无法通过 CSS 去除已尝试 CSS 裁切，效果不好，接受现状。或改用本地 mp4。

❌ 本地 mp4 太大，Git push 超时

原因解决
GitHub 单文件限制 100MB，大文件 push 慢 ① 压缩视频（HandBrake / ffmpeg 降码率）
② 大于 20MB 的视频建议传 B站，用 iframe 嵌入
③ 如果必须用本地且大于 100MB，需配置 Git LFS

❌ 页面显示了但视频没更新（缓存问题）

原因解决
浏览器或 GitHub Pages 缓存了旧版本 ① Ctrl+F5 强制刷新
② 等 1-2 分钟（GitHub Pages 部署延迟）
③ 在 URL 后加 ?v=2 绕过浏览器缓存

❌ 手机上看视频太小或超出屏幕

原因解决
响应式样式未生效 不用管，.video-wrap 和 .video-16x9 自带响应式，手机上会自动缩放
