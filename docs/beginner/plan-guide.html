📋 做事之前先想清楚

你交代小工干活之前，是不是要先想清楚让他干什么？对AI也一样——想清楚了再说，它一次就做对。

① 为什么要先想清楚

一句话

AI 不是你肚里的蛔虫——你不说清楚，它就只能瞎猜。想清楚了再说，它一次就做对，省得反复改。

🏪 好比交代小工干活

你对店里的小工说"去，干点活"——他肯定蒙了，不知道该干啥。

但你说"把门口那箱啤酒搬到冰箱里，摆整齐，过期的挑出来扔掉"——他就知道怎么干了。

跟 AI 说话，一模一样。

你可能会想："我说得再清楚，它不还是AI吗？" 是的，但说清楚和不説清楚，结果差十倍。多花30秒想清楚，省掉来回改的10分钟。

② 万能三步法

每次跟AI说话之前，用这三步想一遍。熟练了之后10秒就能想好。

我是谁 → 我要什么 → 要什么样的

1️⃣ 我是谁

你的身份、你的生意。让AI知道它是在帮谁干活。

"我是开五金店的"
"我是卖茶叶的"
"我是做服装批发的"

2️⃣ 我要什么

具体要做什么事。越具体越好。

"帮我写一段朋友圈文案"
"帮我回这个客户的消息"
"帮我算这个月的利润"

3️⃣ 要什么样的

长度、语气、格式、特别要求。

"口语化、80字"
"客气但不卑微"
"做个表格，清楚点"

💡 这个三步法不是只给AI用的——你交代任何事都用得上。交代员工、写通知、跟供应商谈价格，想清楚这三点，说话就利索了。

③ 糊涂版 vs 清楚版

看几个真实的对比。左边是糊涂版（AI会做错），右边是用三步法改过的（AI一遍就做对）。

❌ 糊涂版

"帮我写个文案"

AI不知道你卖什么、卖给谁、什么风格——写出来多半不能用。

✅ 三步法版

"我是开五金店的（①），帮我写一段朋友圈文案介绍刚到的新螺丝刀套装（②）。要口语化、80字、让人看了想买（③）。"

❌ 糊涂版

"帮我回一下这个客户"

没说客户说了什么、你要什么态度——AI只能乱编。

✅ 三步法版

"我是开网店的（①），帮我回一个客户消息，他说快递三天没到很生气要退款（②）。先道歉，解释是天气原因，最后给他补5块钱优惠券。口语化（③）。"

❌ 糊涂版

"帮我做一个促销方案"

✅ 三步法版

"我是开小超市的（①），国庆快到了帮我策划一个促销活动（②）。主要卖零食和饮料，预算500块，活动搞三天。给我几个方案让我选（③）。"

④ /plan 命令怎么用

三步法适合简单的事。但有些事比较复杂——比如"帮我策划一周的朋友圈内容"。这种时候用 /plan 命令，让AI先帮你理清思路。

/plan 做了什么

你输入 /plan 你想做的事，AI不会马上动手——它会先列一个计划给你看。你觉得可以，它再做。你觉得不对，改完计划再让它做。

就像你让小工干一件复杂活——先让他说说打算怎么干，你点头了他再动手。省得干了一半发现不对。

/plan 不是什么高级功能——它就是"AI先列计划给你确认"而已。不是只有程序员才能用。你策划促销活动、整理仓库、安排一周工作，都能用它。

⑤ 实战例子

📱 例子1：策划一周朋友圈

在 Claude Code 里输入：

/plan 我是卖茶叶的，帮我策划一周的朋友圈内容。周一到周日每天一条，要有产品介绍、客户反馈、茶叶知识、促销信息。不要太硬广，让人看了觉得有用。

AI 会先列出7天的主题、每天发什么、大概的文案方向——你确认了它再一条条写。

📊 例子2：整理客户信息

/plan 我是做服装批发的，手上有50多个客户的联系方式、拿货记录、欠款情况，散落在微信聊天和本子上。帮我想一个整理方案，让这些信息以后好查。

📦 例子3：规划促销活动

/plan 我开了一家小超市，下个月店庆一周年。帮我策划一个店庆活动：做什么促销、怎么通知老客户、需要准备什么东西、预算大概多少。预算是1000块。
💡 看出来了吗：这三个例子，没有一个是跟写代码有关系的。全部是你做生意用得上的。/plan 就是一个"让AI帮你把想法整理成步骤"的工具。

⑥ 第一次用它做计划

现在就试一个。挑一个跟你生意相关的，照着做。

📋 跟做步骤

1. 打开 PowerShell → 输入 claude → 回车

2. 输入 /plan 后面跟上你想做的事。从下面选一个，或者自己想一个：

• /plan 帮我规划一周的朋友圈内容，我是卖___的

• /plan 帮我整理店里的库存，以后好管理

• /plan 帮我策划下个月的促销活动

3. 看看AI列的计划——觉得OK就说"可以，开始做"

4. 觉得不对就说"第三点改一下""加一个XX""第一步不要"

别怕改：计划不是合同。你随时可以改、随时可以重来。AI不会嫌你烦，改一百次它都照做。

⑦ 动手试试

用 /plan 试做下面这些事。每个都跟生意有关，挑一个你最近正好需要的。

📱 朋友圈规划

/plan 帮我规划一周的朋友圈内容。我是卖水果的，想要有产品图、客户好评、水果知识、特价信息。不要太广告。

📊 客户管理

/plan 我是做批发生意的，有30多个老客户。帮我想一个方法，记录每个客户的拿货习惯和欠款情况，以后翻起来方便。

🎯 促销策划

/plan 我是开小超市的，中秋节快到了。帮我策划中秋促销：礼品组合、定价、宣传文案、怎么通知老客户。预算1000。

📋 日常工作安排

/plan 帮我规划每天的固定工作流程。我是开店的，每天要理货、回客户消息、发朋友圈、记账、补货。

⑧ 快速掌握清单

情况怎么做
简单的事（写个文案、回个消息）直接用三步法：我是谁+我要什么+要什么样的
复杂的事（策划活动、整理信息）用 /plan 先列计划，确认再动手
AI列的计划不对直接说哪里不对、要怎么改，AI会调整
不知道从哪开始用 /plan 把想法说出来，让AI帮你理
怕AI跑偏用 /plan，它先列计划给你看，不会乱跑

⑨ 总结：最常用 & 最易错

🎯 记住这三点

✅ 三步法万能——我是谁+我要什么+要什么样的。任何事都先用这个想一遍。

✅ 复杂事用 /plan——让AI先列计划给你看，确认了再让它做。

✅ 不满意就改计划——计划不是合同，随时改。AI不会嫌烦。

⚠️ 别犯这三个错

❌ 觉得 /plan 是给程序员用的——你策划活动、安排工作、整理信息，全都能用它。

❌ 说了第一步不说后两步——"我是开店的（①）"完了就不说了。AI还是不知道你要什么。

❌ 计划要完美了才动手——不用。大概对就行，边做边改。
