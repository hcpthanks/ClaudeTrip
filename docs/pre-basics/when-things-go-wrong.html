① 先搞懂一件事——报错不是你的错

老王第一次看到满屏红字的时候，差点把电脑砸了。
后来才知道——那些红字不是骂他，是电脑在"喊救命"。
红色的 ERROR 不是骂你"搞错了"
是电脑在说："我遇到了一个我不会处理的情况，你能帮我看看吗？"

🚗 用开车比喻报错

场景相当于…
仪表盘亮红灯电脑屏幕出现红色 ERROR
你把车开到修车店把报错信息发给 AI
师傅看一眼仪表盘AI 读一遍报错文字
师傅说"换个刹车片就好了"AI 说"执行这条命令就好了"

你不需要懂修车，你只需要知道怎么把车开到修车店。报错同理——你不需要懂报错什么意思，你只需要会把它发给 AI。就像车仪表盘亮红灯——不是骂你开车技术差，是告诉你该换机油了。

② 一步一步来：遇到报错的 SOP

SOP = 标准处理流程。以后每次遇到报错，照这三步做。
💡 示意图仅供参考。

  1. 1

    深呼吸——先别慌

    看到红字的第一反应是"完了，我把电脑弄坏了"。但不是——99% 的报错不是你弄坏的。
    记住一句话：只要电脑还能开机，就没事。最坏的情况不过是重装——重装也不难。
  2. 2

    截图——把报错拍下来

    把整个命令行窗口截个图，特别是红色的那几行
    怎么截图？按键盘上的 Win+Shift+S → 鼠标框选 → 自动复制。
  3. 3

    把报错文字复制给 AI

    光有截图还不够——把红字部分复制出来，贴给 Claude Code
  4. 4

    把报错发给 Claude——让它帮你读

    把截图和报错文字一起发给 Claude——就像给修车师傅看照片

    AI 给你回复了吗？照它说的做，90% 的问题这时候就解决了。

③ 再看一遍：报错处理三步法

报错处理三步法
😱 看到红字 → 📸 截图+复制文字 → 🤖 发给 AI 问"怎么修" → ✅ 解决

💡 记牢这三步。你不需要成为修电脑的专家，你只需要成为"把问题发给专家"的专家。

④ 常见报错速查——以后遇到直接来查

报错 1：npm ERR! code EACCES（权限不够）
npm ERR! code EACCES
npm ERR! syscall access
npm ERR! path /usr/local/lib

权限不够。

右键命令行图标 → "以管理员身份运行"，再执行同样命令。
报错 2：'claude' 不是内部或外部命令 / command not found
Win: 'claude' 不是内部或外部命令，也不是可运行的程序

Claude Code 没装好。

关闭所有命令行窗口，重新打开。输入 npm install -g @anthropic-ai/claude-code 重新安装。如果还不行，重启电脑。
报错 3：'npm' 不是内部或外部命令 / command not found
Win: 'npm' 不是内部或外部命令

Node.js 没装或没装好。

关闭所有命令行窗口，重新打开。输入 node --version 验证。如果没有版本号，去 nodejs.org 重新下载安装 Node.js。
报错 4：npm ERR! network / timeout（网络问题）
npm ERR! network request to https://registry.npmjs.org/... failed
npm ERR! network This is a problem related to network connectivity

网络连不上 npm 的服务器。

检查能不能上网（打开浏览器试一下）。如果网络正常，可能是 npm 源的问题——告诉 AI："npm 网络超时，帮我换成国内镜像源"，AI 会帮你配置。

🔄 终极必杀技——重启大法

如果以上方法都不行，试试这个：

关掉命令行 → 关掉所有相关窗口 → 重启电脑 → 重新打开 → 再试

👉 解决率：约 50%。重启能清除很多奇怪的状态。

⑤ 做一遍：动手练习

你的练习任务

1. 在命令行里故意打一个不存在的命令（比如 abcdefg），看报错长什么样子
2. 把报错文字复制出来
3. 启动 claude，把报错贴给它，说"这个报错是什么意思？"
4. 看 AI 怎么回复你

💡 这次是故意制造一个假报错练手。以后遇到真报错就不用怕了——你已经有经验了。
