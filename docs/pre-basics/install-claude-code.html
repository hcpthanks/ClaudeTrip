① 安装 Claude Code 之前，需要先装一个东西

就像要玩手机游戏得先装"应用商店"一样
Claude Code 需要先装一个叫 Node.js 的东西

🏗️ 用盖房子来比喻

步骤相当于…
① 装 Node.js打地基——所有东西都建在它上面
② 装 Claude Code在地基上盖房子——装好就能用

好消息是：两个步骤都只需要在 PowerShell 里输入一句话。全程 5-10 分钟。

② 一步一步来：从零到装好

Part A：安装 Node.js（打地基）

  1. 1

    打开你的浏览器（Edge / Chrome 随便哪个）

    双击桌面上的浏览器图标，或者在任务栏上点它
  2. 2

    在地址栏输入这行网址，然后回车

    在浏览器顶部的长条框里输入：
    nodejs.org
  3. 3

    点那个绿色按钮，下载安装文件

    推荐点左边的 "LTS" 版本（长期稳定版）

    下载完成后，浏览器底部或右上角会显示一个下载完成的提示。文件名类似 node-vXX.XX.X-x64.msi。

  4. 4

    双击下载的文件，一路点 "Next"

    打开下载的文件 → 一直点 "Next" → 最后点 "Finish"
    关键：安装过程中如果出现一个复选框写着"Automatically install the necessary tools"，不要勾选。直接点 Next 跳过。
  5. 5

    验证 Node.js 装好了没有

    重新打开一个 PowerShell 窗口（关掉旧的，重新打开），输入：
    node --version

    然后按回车键（Enter）

    你看到版本号了吗？（是一串数字，像 v20.11.0）

🏗️

地基打好了！Node.js 安装完成

接下来只需要一句话，就能装上 Claude Code。

Part B：安装 Claude Code（盖房子）

  1. 6

    在 PowerShell 里输入这一句话

    复制下面这行命令，粘贴到 PowerShell 里，按回车：
    npm install -g @anthropic-ai/claude-code

    怎么粘贴？在 PowerShell 窗口里点右键，文字就贴上去了。

    安装过程中你会看到很多英文在滚动——这是正常的。只要没有红色的"ERROR"，就说明在正常进行。

  2. 7

    验证 Claude Code 装好了没有

    安装完成后，输入：
    claude --version

    出现版本号（一串数字）= 安装成功。如果出现红色报错，跳到下面的"常见坑"看解决方案。

🎉🎉🎉

全部安装完成！你的电脑现在有了 AI 助手

从零到装好，你只用了不到 10 分钟。下一步就是跟它说"你好"了。

④ 最容易遇到的 3 个问题

坑 1：输入 npm 命令后说 "npm 不是内部或外部命令"

Node.js 没装好，或者装了之后没重启 PowerShell。

第一步：关掉所有 PowerShell 窗口，重新打开一个新的。第二步：输入 node --version 看有没有版本号。如果没有，重新装一遍 Node.js（先卸载，再重装）。
坑 2：安装过程中出现红色 ERROR

通常是网络问题或者权限不够。

先检查网络能不能上网（打开浏览器试一下）。如果网络正常，试试用管理员身份打开 PowerShell（右键 PowerShell 图标 → "以管理员身份运行"），再执行安装命令。
坑 3：装好了但 claude --version 没反应

安装可能没有加到系统路径里。

关掉 PowerShell，重新打开一个新的，再试。如果还是不行，重启电脑——重启能解决 80% 的奇怪问题。

⑤ 做一遍：动手练习

你的练习任务

1. 打开 PowerShell，输入 node --version，确认 Node.js 装好了
2. 输入 npm --version，确认 npm 也可以用
3. 输入 claude --version，确认 Claude Code 装好了
4. 如果上面三步都 OK——给自己点个赞 👍

💡 这三个命令是你以后会反复用到的"体检命令"——随时检查东西装好了没有。
