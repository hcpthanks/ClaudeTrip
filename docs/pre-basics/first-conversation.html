② 一步一步来：从打开到第一次对话

  1. 1

    打开 PowerShell

    还记得怎么打开吗？（搜索 → 输入 powershell → 点图标）
    如果不记得了：回去看看 打开 PowerShell 那节课。这是最后一次提醒——以后你就能自己开了。
  2. 2

    输入 "claude"，然后按回车

    在 PowerShell 那个闪烁的光标处，打 6 个字母：c-l-a-u-d-e，然后按 Enter 键

    按回车后，你应该看到一些文字开始出现。这是 AI 在"启动"——就像打开一个 App 需要等几秒。

  3. 3

    第一次启动可能要登录

    如果是第一次用，可能会让你登录 Anthropic 账号
    登录一次就够了。以后每次输入 claude 都会直接进入对话，不需要重新登录。
  4. 4

    AI 准备好后，你会看到它跟你打招呼

    启动完成后，Claude 会主动跟你说话

    你应该看到 Claude 给你发了一段消息，最下面有个闪烁的光标——那是你打字的地方。

  5. 5

    说"你好"——开始第一次对话

    在光标处打字，说你想说的，按回车发送
  6. 6

    AI 在"思考"的时候，你会看到画面在动

    你发送消息后，AI 不会马上回复——它需要几秒思考

    AI 开始回复了吗？如果回复了——你刚刚完成了人生中第一次跟 AI 的工作对话！

  7. 7

    怎么结束对话

    想退出的时候，输入 /exit 或者直接关掉窗口
    /exit

    输入 /exit 然后按回车，就会回到普通的 PowerShell。或者直接点窗口右上角的 ✕ 关掉。

④ 最容易遇到的 3 个问题

坑 1：输入 claude 后说"不是内部或外部命令"

Claude Code 没装好。

回到 安装那节课，重新执行 npm install -g @anthropic-ai/claude-code。如果装了还不行，关掉 PowerShell 重新打开一个新的。
坑 2：启动后一直没反应

可能是第一次启动需要登录，但登录页面没弹出来。

仔细看 PowerShell 窗口里的文字——里面可能有一个网址。把那个网址复制到浏览器打开，完成登录。
坑 3：不知道跟 AI 说什么

AI 在等你说话，但你不知道说什么好。

试试这几句："你好，介绍一下你自己"、"帮我写一段个人简介"、"我最近想学XX，你有什么建议？"——把这些当练手。

⑤ 做一遍：动手练习

你的练习任务

1. 打开 PowerShell，输入 claude 启动 AI
2. 跟 AI 说："你好，请介绍一下你自己"
3. 再问它一个问题（任何你想知道的事）
4. 输入 /exit 退出

💡 试试让它帮你写点东西。比如："帮我写一封请假邮件，就说我感冒了，明天请假一天"——看它怎么回复。
