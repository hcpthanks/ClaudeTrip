Claude Code 原装的"发动机"（Claude 模型）在国内用不了。就像一台好车配了个国外才能加的油——车没问题，油进不来。

解决办法：换一个国产发动机——DeepSeek。它是中国公司做的 AI 模型，国内直接能用，价格便宜（充 10 块钱能用好几个月），效果也很不错。

这节课要做什么：给 Claude Code 装一个"转换器"（叫 ccswitch），让它能使用 DeepSeek 这个国产发动机。全程 15 分钟，不花一分钱（DeepSeek 新用户送免费额度）。

② 一步一步来：装转换器 + 换发动机

  1. 1

    安装 ccswitch（转换器）

    打开 PowerShell，输入下面这行命令，按回车：
    npm install -g ccswitch
    这是什么？ccswitch 是一个小工具，专门帮 Claude Code 切换不同的 AI 模型。就像手机换 SIM 卡——换一张卡就能用不同运营商，换一个模型 Claude Code 就能用不同的 AI。

    ✅ 检查点：出现 "+ ccswitch" 字样了吗？出现了就继续下一步。

  2. 2

    打开 ccswitch

    在 PowerShell 里输入 ccswitch，按回车
    ccswitch

    ✅ 检查点：看到 ccswitch 的配置面板了吗？能看到几个模型供应商的图标？

  3. 3

    去 DeepSeek 官网拿"钥匙"（API Key）

    打开浏览器，访问 DeepSeek 官网

    🔑 什么是 API Key？——用住酒店来理解

    你去酒店前台登记，拿到一张房卡。只有这张卡才能打开你的房间门。
    API Key 就是这张"房卡"——你用它告诉 DeepSeek："是我在用，请让我进去。"
    区别是：酒店房卡只能用一个房间，API Key 是按用量扣费（用多少扣多少，很便宜）。

    1. 打开 DeepSeek 官网：
      在浏览器地址栏输入 chat.deepseek.com，按回车
      （如果你已经有 DeepSeek 账号，直接登录；没有的话用手机号注册一个——跟注册微信差不多）
    2. 进入 API 开放平台：
      登录后，点页面右上角的 "API 开放平台" 按钮
    3. 创建 API Key：
      进入 API 平台后，点左侧菜单的 "API Keys"，然后点 "创建 API Key" 按钮
    4. ⚠️ 重要！复制并保存你的 API Key：
      创建后会弹出一个窗口，显示一串字母和数字（像这样：sk-xxxxxxxxxxxxxxxxxxxxxxxx）
      🚨 这个窗口关掉之后就再也看不到了！必须现在就复制下来，保存到一个安全的地方。
      建议：新建一个记事本文件，粘贴进去，保存到桌面。文件名就叫"DeepSeek钥匙.txt"

    ✅ 检查点：你的 DeepSeek API Key 已经复制到记事本里了吗？是不是以 sk- 开头的一长串字母数字？

  4. 4

    把 DeepSeek 的"钥匙"交给 ccswitch

    回到 ccswitch 面板，找到 DeepSeek，填入你的 API Key
    1. 在 ccswitch 配置页面里，找到并点击 DeepSeek
    2. 往下滑，找到 "API Key" 输入框
    3. 把你刚才保存的那串 sk- 开头的钥匙，粘贴进去
    请求地址和 API 格式不用改——ccswitch 已经帮你填好了。你只需要填 API Key 和改模型名。然后点 "保存"。
    模型名后面的 [1m] 是什么意思？1m = 100 万。这个标记告诉 DeepSeek："我可以一次跟你说很多话（100 万个词的上下文）"。不加这个标记的话，AI 的"记忆力"会变差。

    ✅ 检查点：API Key 粘贴好了吗？模型名改成 deepseek-v4-flash[1m] 了吗？点了保存吗？

  5. 5

    验证——看看是不是真的能用了

    回到 PowerShell，输入 claude，按回车启动
    claude

    第一次启动可能会问你"是否信任"——按 1 然后回车（选"信任"）。

    启动后，输入这句话来验证：

    你是什么模型？
    我是 DeepSeek-V4-Flash，由深度求索公司开发的大语言模型……

    ✅ 检查点：AI 回答里有没有 "DeepSeek" 这几个字？有的话就说明换发动机成功！

  6. 6

    （可选）如果提示"余额不足"——给 DeepSeek 充值

    大部分新用户有免费额度。如果用完了，才需要充值。

    💰 充多少钱够用？

    DeepSeek 非常便宜——充 10 块钱，个人正常用能用好几个月。
    就像交手机费：不是按月交很多，而是用多少扣多少。偶尔用用的话，一个月几毛钱。
    充值方法：回到 DeepSeek API 平台 → 左侧菜单点"充值" → 微信/支付宝扫码付钱。

    别担心花钱。相比 Claude 官方每月 20 美元（约 140 人民币）的订阅费，DeepSeek 便宜了 100 倍不止。这就是为什么我们说"换国产发动机更划算"。

④ 最容易遇到的 4 个问题

坑 1：输入 ccswitch 说"不是内部或外部命令"

ccswitch 没装好。

重新在 PowerShell 里输入 npm install -g ccswitch，等它跑完。如果还是不行，关掉 PowerShell 重新打开一个再试。
坑 2：配置好之后，Claude Code 还是连不上 / 报错

90% 是因为 API Key 没填对。

检查三件事：
① API Key 是不是完整复制了？（sk- 开头，后面一大串）有没有多复制空格？
② 请求地址是不是 https://api.deepseek.com/anthropic？
③ API Key 对应的 DeepSeek 账号里有没有余额？（新用户一般有免费额度，如果用完了去充 10 块）
坑 3：API Key 找不到了（关掉窗口后忘了保存）

创建 API Key 时关掉弹窗就再也看不到了。

回到 DeepSeek API 平台 → API Keys 页面 → 删掉旧的 → 创建一个新的。这次记得马上复制到记事本保存。
坑 4：AI 回答很慢或者回答一半就停了

可能是模型名没写对，或者网络波动。

检查模型名是不是 deepseek-v4-flash[1m]——注意后面的 [1m] 不能漏。
如果模型名没错，可能是网络问题——等几分钟再试。DeepSeek 在国内的服务器很稳定，偶尔卡一下正常。
