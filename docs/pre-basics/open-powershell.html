① 什么是 PowerShell？为什么你要学它？

PowerShell = 你打字给电脑下命令的地方
学完这节课，你能自己打开它，看到那个蓝色/黑色的窗口

📱 把它想象成"跟电脑发微信"

你用手机的时候用 PowerShell 的时候
打开微信，找到联系人打开 PowerShell，看到一个窗口
打字发消息："明天几点见？"打字发命令："帮我创建一个文件夹"
对方回复你电脑执行你的命令，显示结果

区别只有一个：你发微信是用中文聊天，PowerShell 里用的是简短的英文命令。但别怕——以后 90% 的命令都是 AI 帮你写的，你只需要会打开这个窗口就行。

Claude Code 就在 PowerShell 里运行。所以你要先学会打开 PowerShell，才能用 Claude Code。这是第一步。

② 一步一步来：三种打开方式

三种方法都能打开，选一个你最喜欢的。推荐方法一（最简单）。

🔍 方法一：搜索打开（最推荐 👍）

大多数人用的方法——最快最简单。

  1. 1

    点一下任务栏上的搜索框

    任务栏上有个放大镜图标或搜索框，点它
  2. 2

    输入 "powershell"

    在搜索框里打这 10 个字母：p-o-w-e-r-s-h-e-l-l

    输入后，搜索框下面是不是出现了一个蓝色图标、旁边写着 "Windows PowerShell"？

  3. 3

    点一下那个蓝色图标，打开它

    用鼠标左键点一下搜索结果里的 "Windows PowerShell"
🎉

你打开了 PowerShell！

你看，没那么难对吧？这个窗口以后就是你和 AI 聊天的地方。

🖱️ 方法二：右键开始菜单（备选）

如果方法一搜不到，试试这个。

  1. 1

    在开始菜单图标上点"右键"

    鼠标移到左下角开始菜单图标 → 点右键（不是左键！）
  2. 2

    在菜单里找到 "Windows PowerShell"，左键点它

    在弹出的菜单里找到这几个字，左键点一下

    弹出来的菜单里应该有 "Windows PowerShell" 这一项。点一下就打开了。

📁 方法三：在文件夹里打开（高级）

以后你可能会在特定文件夹里打开 PowerShell——Claude Code 需要在你的项目文件夹里运行。

这个方法现在不用学。等你看完"文件与文件夹"那节课再回来学也不迟。现在用方法一就够了。

✅ 打开了！它长什么样？

窗口打开后，你应该看到类似 PS C:\Users\你的名字> 这样一行字，最后有个闪烁的光标。

④ 最容易遇到的 3 个问题

坑 1：搜 "powershell" 搜不到

可能是拼错了，或者 Windows 版本比较旧。

检查拼写：p-o-w-e-r-s-h-e-l-l（没有空格，结尾两个 L）。如果还是搜不到，试试搜 "cmd"（命令提示符），功能差不多。或者用方法二（右键开始菜单）。
坑 2：窗口一闪就没了

点开之后窗口闪了一下就消失了。

试试：在搜索结果的 "Windows PowerShell" 上点右键 → 选择"以管理员身份运行"。如果还不行，重启电脑再试。
坑 3：窗口里的字看不懂

打开后看到一堆英文，不知道什么意思。

正常！现在你只需要知道一件事：那个闪烁的光标就是你打字的地方。其余的字是电脑在告诉你"我准备好了"。以后 AI 会帮你处理这些。

⑤ 做一遍：动手练习

你的练习任务

1. 用方法一（搜索）打开 PowerShell
2. 看看窗口里那个闪烁的光标——你找到它了吗？
3. 关掉窗口（点 ✕）
4. 等 5 秒，用方法一再打开一次
5. 再关掉，用方法二（右键开始菜单）打开

💡 目标：你能用至少两种方法打开 PowerShell。反复练到不需要看教程为止。
