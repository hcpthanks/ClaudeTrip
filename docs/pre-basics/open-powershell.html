① 什么是命令行？为什么你要学它？

命令行 = 你打字给电脑下命令的地方
Windows 10 叫 PowerShell
学完这节课，你能自己打开它，看到那个带光标的小窗口

👴 老王第一次看到那个黑窗口的时候

吓得赶紧关掉了。后来才知道——那只是电脑的另一种"说话方式"。

就像你可以用嘴说"帮我拿瓶水"，也可以用手机发微信"帮我拿瓶水"——目的都一样，方式不同。

黑窗口 = 你用打字跟电脑说话的地方。不用鼠标点点点，打字就行。

📱 把它想象成"跟电脑发微信"

你用手机的时候用命令行的时候
打开微信，找到联系人打开命令行，看到一个窗口
打字发消息："明天几点见？"打字发命令："帮我创建一个文件夹"
对方回复你电脑执行你的命令，显示结果

区别只有一个：你发微信是用中文聊天，命令行里用的是简短的英文命令。但别怕——以后 90% 的命令都是 AI 帮你写的，你只需要会打开这个窗口就行。

Claude Code 就在命令行里运行。所以你要先学会打开命令行，才能用 Claude Code。这是第一步。

② 一步一步来：打开 PowerShell

⊞ Windows 10 用户看这里

两种方法都能打开，推荐方法一（最简单）。老王第一次打开用了一分钟。你也能。
💡 示意图仅供参考，不同 Windows 版本界面可能略有差异。

🔍 方法一：搜索打开（最推荐 👍）

大多数人用的方法——最快最简单。

  1. 1

    点一下任务栏上的搜索框

    任务栏上有个放大镜图标或搜索框，点它
  2. 2

    输入 "powershell"

    在搜索框里打这 10 个字母：p-o-w-e-r-s-h-e-l-l

    输入后，搜索框下面是不是出现了一个蓝色图标、旁边写着 "Windows PowerShell"？

  3. 3

    点一下那个蓝色图标，打开它

    用鼠标左键点一下搜索结果里的 "Windows PowerShell"
🎉

你打开了 PowerShell！

你看，没那么难对吧？这个窗口以后就是你和 AI 聊天的地方。

🖱️ 方法二：右键开始菜单（备选）

如果方法一搜不到，试试这个。

  1. 1

    在开始菜单图标上点"右键"

    鼠标移到左下角开始菜单图标 → 点右键（不是左键！）
  2. 2

    在菜单里找到 "Windows PowerShell"，左键点它

    弹出来的菜单里应该有 "Windows PowerShell" 这一项。点一下就打开了。

✅ 打开了！它长什么样？

窗口打开后，你应该看到类似 PS C:\Users\你的名字> 这样一行字，最后有个闪烁的光标。

④ 最容易遇到问题

⊞ Windows 10 常见坑
坑 1：搜 "powershell" 搜不到

可能是拼错了，或者 Windows 版本比较旧。搜不到就像在店里找不到螺丝刀——不是没有，是名字没叫对。

检查拼写：p-o-w-e-r-s-h-e-l-l（没有空格，结尾两个 L）。如果还是搜不到，试试搜 "cmd"（命令提示符），功能差不多。或者用方法二（右键开始菜单）。
坑 2：窗口一闪就没了

点开之后窗口闪了一下就消失了。

试试：在搜索结果的 "Windows PowerShell" 上点右键 → 选择"以管理员身份运行"。如果还不行，重启电脑再试。
共同坑：窗口里的字看不懂

打开后看到一些英文+符号，不知道什么意思。

正常！现在你只需要知道一件事：那个闪烁的光标就是你打字的地方。其余的字是电脑在告诉你"我准备好了"。以后 AI 会帮你处理这些。

⑤ 做一遍：动手练习

你的练习任务

1. 打开命令行（搜 powershell）
2. 看看窗口里那个闪烁的光标——你找到它了吗？
3. 试着输入 helo 回车——看电脑怎么告诉你它没听懂。这就像你对店员说错的货名，店员会反问"你说的是螺丝刀吗？"
4. 关掉窗口
5. 等 5 秒，用同样方法再打开一次
6. 再关掉，用备选方法打开一次（右键开始菜单）

💡 目标：你能用至少两种方法打开命令行。反复练到不需要看教程为止。故意打错字那一步很重要——以后遇到红字就不会怕了。
