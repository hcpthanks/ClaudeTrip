🧱 一步一步搭建

用 Claude Code 从零搭起视频工厂。全程不需要你写一行代码。

1

告诉 Claude 你要做什么

打开 Claude Code，输入需求："我要一个视频生成工具，输入文案自动生成带配音字幕的 MP4"。Claude 会用 /plan 帮你制定方案。

2

配置 MCP 接入 Agnes AI

在 .mcp.json 里注册 Agnes 三个模型。Claude 帮你生成配置，你只需要填入免费 API Key。

3

选 TTS 引擎、装模型

edge-tts 云端免费直接能用；CosyVoice2（~5.3GB 本地）或 Qwen3-TTS（~2.4GB 本地）音质更好。Claude 帮你装好。

4

跑通第一条视频

终端输入：python generate.py -t "你的文案" -o output.mp4 。几分钟后拿到带配音+字幕的完整视频。

📱 实战案例

🎬 15 秒抖音知识类短视频

输入文案："Claude Code 有个 /plan 命令，做任何事之前先规划，确认后再执行。这样不会浪费钱，也不会做错方向。"

流程：
① Claude 解析文案 → 拆成 5 句字幕
② Agnes Video 生成 15 秒画面（361 帧，num_frames = 8×45+1 = 361）
③ edge-tts xiaoxiao 配音 → 生成 SRT 字幕
④ FFmpeg 合成 → 15 秒 MP4（1088×832，约 3MB）

结果：从输入文案到可发抖音的视频，不到 3 分钟。全程不需要打开任何设计软件。
