📱 实战案例

🎬 3 分钟知识视频：从文章到专业成片

输入文案：一篇 2000 字的科普文章

v2.0 全流程：
① Claude 解析文章 → 拆成 8 个段落
② edge-tts xiaoxiao 为每段配音 → 自动生成 SRT 字幕
③ Agnes Video 为每段生成 AI 画面（361帧/段，num_frames = 8n+1）
④ Shotcut CLI 将 8 段拼接，段间 dissolve 1s 转场，片头 fade-in 1.5s
⑤ Audacity CLI 混入 BGM（音量 -16dB，不盖过人声）
⑥ SoX 对人声做 normalize + compand 降噪
⑦ FFmpeg 合成最终 MP4（1080p，H.264）

结果：从输入文章到可发布的 3 分钟专业视频，不到 8 分钟。
全程不需要打开任何剪辑软件——不需要学 Shotcut，不需要学 Audacity，不需要学任何东西。

1

MLT XML 项目文件格式

Shotcut 用 MLT 框架的 XML 格式组织项目。研究它的 XML schema、track/producer/filter 层级关系、时间线坐标编码——然后让 Claude Code 自动生成正确格式的 .mlt 文件。

2

多轨混音参数调试

SoX 的 compand 动态压缩参数（attack/decay/knee/gain）直接影响人声自然度。调试出 BGM -16dB 不盖人声、fade-in 0.5s 不做作的参数花了大量时间。

3

多 CLI 错误处理

melt 渲染路径空格需双引号包裹、SoX 32位限制 2GB 单文件、Shotcut CLI 需 --project 标志预打开项目——每个坑都是踩出来的。
