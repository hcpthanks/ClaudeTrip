**日期**: 2026-06-21
**状态**: 已确认

## 一、项目目标

在 hcpthanks.com 上新增"关于作者"个人主页，对外展示：
- **我是谁** — 个人定位和方法论
- **我能做什么** — 技能和项目作品
- **怎么联系我** — 服务和联系方式

目标是让访问者了解作者的能力和风格，建立信任感，为潜在合作打下基础。

## 二、核心定位

**一句话定位**: "让每个人都能用 AI 干活"

**核心叙事**: 我不写代码，但我用 AI 工具把想法变成了产品。你看得到的这些网站、工具、系统——都是我跟 AI 对话做出来的。

**目标受众**（综合型）:
- 零基础想用 AI 工具的人
- 商户/个体户
- 想省时间的普通用户
- 潜在合作方

**差异化**: "先行者"而非"专家"——自己从零走过来，特别懂零基础用户的痛点。

## 五、技术方案

### 5.1 文件结构

```
新增文件:
├── docs/about.html                          # 完整个人主页
├── claude-code-learning-site/about.html     # 同步副本

修改文件:
├── docs/index.html                          # +首页作者卡片
├── claude-code-learning-site/index.html     # +首页作者卡片（同步）
├── docs/assets/js/nav.js                    # +导航"关于作者"链接
├── claude-code-learning-site/assets/js/nav.js  # 同步
```

### 5.2 样式策略

- 复用 `common.css` 设计令牌（`--bg`, `--surface`, `--border`, `--accent`, `--text` 等）
- 页面内联 `<style>` 仅写 about.html 特有样式
- 首页作者卡片样式写在 `docs/index.html` 的现有 `<style>` 块中

### 5.3 导航变更

`nav.js` 加一行：桌面导航和移动端 hamburger 菜单各加一个"关于作者"链接，指向 `/about`。

### 5.4 部署

- 文件放入 `docs/` → 自动通过 GitHub Pages 上线
- 同步到 `claude-code-learning-site/` → 满足双目录同步规则
- URL: `https://www.hcpthanks.com/about`（GitHub Pages 自动无扩展名路由）

### 5.5 设计令牌复用

| 变量 | 值 | 用途 |
|------|-----|------|
| `--bg` | `#0d1117` | 页面背景 |
| `--surface` | `#161b22` | 卡片背景 |
| `--border` | `#30363d` | 分隔线 |
| `--accent` | `#58a6ff` | 强调色（链接、按钮、高亮） |
| `--text` | `#c9d1d9` | 正文 |
| `--text-muted` | `#8b949e` | 次要文字 |
| `--green` | `#3fb950` | 方法论阶段标记 |
| `--purple` | `#a371f7` | 项目标签 |
